Anaconda 和 Miniconda 每周被下载约一百万次。这个数字背后藏着一件很少被公开讨论的事：全世界靠 Python 吃饭的人，远比官方统计的“一千万 Python 程序员”要多得多。真正撑起这个生态的，是一群从不把自己当程序员的人。

彼得·王（Peter Wang）就是这群人里走得最远的那个之一。物理学出身，C++ 图形性能优化起家，后来成了 Python 数据科学生态最重要的建设者之一，Continuum Analytics（后来的 Anaconda）联合创始人。他在 Lex Fridman 播客里聊了将近三个小时，从 Python 最优雅的特性，一路聊到企业算不算人、意识从哪来、生命的意义是什么。

这期对话的信息密度极高，而且经常在工程细节和形而上学之间来回跳跃。下面把它拆开讲清楚。

为什么是 Python 抓住了他

彼得第一次用 Python 是在九十年代末，当时他是个沉迷 C++ 图形性能的工程师。那个年代用 C++ 写高阶抽象极其痛苦，模板支持不好，编译器也跟不上。转到 Python 之后，他第一次遇到真正把函数和类型当一等公民对待的语言。

我有个朋友说得特别好：Python 就是刚好装得进我的脑子。（彼得·王）

这句话比任何技术分析都准确。他提到，一门语言能不能“装进脑子”，取决于你有没有选对受众。受众越明确、需求越紧凑，就越容易找到一个紧凑的投影把他们的需求装进去。受众越多元，这件事就越难。Python 变得越来越流行，复杂度也自然跟着涨，因为任何一个设计决策都会冒出多个都说得通的立场。这是流行度的代价，几乎无法避免。

他还提到一个更微妙的点：让他一直爱着 Python 的，是元类（metaclass）和 NumPy 向量化这两件事并列。前者让他能随手搭出新的对象模型去描述世界，后者让他习惯用矩阵和向量的方式思考。这两样东西的共同点是，工具本身足够简单，简单到你不会在“理解工具”上浪费精力，可以把全部注意力放在要解决的问题上。

一个面包车装下的人，创造了每天几十亿美元的价值

彼得让 Lex 估算一下 SciPy 那一套核心库（NumPy、SciPy、Matplotlib、IPython、pandas、scikit-learn）今天在世界上创造了多少经济价值。Lex 猜至少每天十亿美元。彼得说，可能还不止，光是那些机构“如果没有这些工具就根本做不到的事”，就已经是每天几十亿美元的量级。

造出这套东西的人有多少？

曾经有一段时间，这些人一辆面包车就能装下。我开的那辆奔驰面包车就能装下他们。（彼得·王）

十来个人，一辆车，创造每天几十亿美元的价值。他把这个事实摆出来，然后问了一个尖锐的问题：如果一家对冲基金只要雇十二个人就能造出每天值几十亿美元的东西，那每一家对冲基金都会抢着去干。但没人干得成。因为找到对的人、培育出对的协作关系、让对的人接手继续打磨，这个过程是自然生长出来的，靠的是众包，靠的是开源的那套精神，招聘和 KPI 堆不出这种东西。

更值得琢磨的是这些人当时的动机。这些人压根没想过什么每天几十亿美元的项目。他们是电气工程的博士生、助理教授，在拿 Python 解决自己领域里的具体问题。资源有限反而成了一种筛选：如果工具太难用，他们根本不会去造，因为那只是个业余项目。所以能被造出来的，一定是刚好够用、足够紧凑、表达式足够强的东西。

彼得在这里引用了 Jamie Zawinski 的一句名言：每个极客的梦想都是造出终极中间件。但这些科学家转型的业余程序员没有这个梦想。他们只想写一个比 MATLAB 顺手一点点的东西，然后复用别人已经造好的部分。结果在一种类似退火的过程里，整个科学生态的基本需求被模块化地覆盖了。

他由此得出一个结论：当资源极度充足时，人们倾向于造终极中间件；当资源极度匮乏时，人们才造出真正有用的东西。

软件时代正在结束

彼得反复提到一个判断：我们正在走到“纯软件时代”的尽头，进入一个赛博系统（cybernetic system）的黎明。

过去四十年，软件正确性的定义基本就是函数正确性：写好一个函数，给它输入，看输出对不对，对就上线接数据库。机器学习系统打破了这个定义。输入的具体数值本身，必须和函数一起考虑，才能判断整个系统是否正确。再加上一个性能的 SLA（服务等级协议），比如必须在十毫秒内返回某个精度级别的预测。

这带来一个根本性的变化：以前那种“用沙盒里的测试输入验证一下就能上线”的模式失效了。因为你会遇到一些输入，需要多花一点时间想清楚；还会遇到一些输入，压根就不清楚该怎么办。于是软件的运行时间和正确性都会随输入浮动。到这一步，系统的性质已经变了。

他举了电子市场的例子。这是世界上最大的赛博系统，没有任何个人能控制它。闪崩（flash crash）经常发生。高频交易的黄金年代，市场微观结构里出现了大量设计者根本没想过、没预料到的行为。人一旦从回路里被拿掉，系统的设计者和工程师能预测后果的能力就急剧下降，哪怕他们出发点是好的。

利比亚那批带着炸药飞出去的自主杀伤无人机，在他看来就是这个趋势的一个早期样本。设计者给了一个大致目标，但目标本身并不精确。人在回路外，机器自己决定下一步该做什么来获取更多信息，这就是赛博系统。

企业算不算人

彼得在这件事上的立场分两层。

第一层，他认为一群人确实具有某种“中观尺度”（mesoscopic）的能动性和主权。这个想法并不离谱。我们已经在法律里编码了类似概念：婚姻关系里，一方可以就“配偶权丧失”（loss of consortium）起诉；教会、俱乐部，我们谈论它们时都当作有真实能动性的集体。国家更是如此，所有人都按“法国是一个东西、美国是一个东西”的方式玩游戏。

第二层出问题的地方，在于这种能动性被某一种特定形态的企业垄断了。

最流行的版本是那种盈利性的、由缺席所有者持有的公司，它能积累起比这片土地上任何其他实体都多的资源，然后它就能欺负个人，无论对方是劳动者，还是它想攫取资源的人。它还能欺负我们那套仍然和个人绑定的代议制度。所以我不认为这是对的。我不觉得它们是人就该被表扬，它们是混蛋。（彼得·王）

所以集体有能动性这件事本身说得通，他要强调的是另一件事：关系也有关系。

八个人围坐一桌，每个人都有和其他每个人的关系，这很明显。但如果这是四对伴侣，每一对伴侣也和另外每一对伴侣有关系。如果这里面有一对是父母，另一对是他们的孩子和配偶，那么这两个四口之家组成的单元之间也有关系。这种“关系之间的关系”，我们在日常社交里凭直觉就知道，但很少被明确说出来，更少在系统设计时被认真考虑。

他关心这件事的原因很实际：人类的未来需要更好的集体意义建构单元，规模大概在邓巴数（Dunbar's number）的一半到五倍之间。而现状是两个极端，要么把意义建构外包给庞大而僵化的僵尸机构，要么完全靠自己一个人硬扛，独自走进互联网的黑暗森林。

邓巴数能不能被技术放大

Lex 提出一个反问：邓巴数是不是被过度当成一条铁律了？如果工具对了，人是不是能深度连接更多人？

彼得的回答是：可以扩，但有上限。他引用了朋友 Joe Edelman 的说法，建立信任有几种方式：相互欣赏、建设性的冲突、共同经历某些事情。所有这些都需要时间，需要你在场。在场越少，能同时维持的关系越多，但每一段关系就越浅。这里同样没有免费午餐。

也有例外。如果你写一本小册子讲你的世界观，我异步读到，觉得“这人跟我在一个频道上”，然后我写一本给你看，你也觉得是。我们可能一年只见几次面，却能维持高信任关系。这种异步的方式确实能扩展一点容量。

但这要求个体本身有一定的容量。用大五人格的话说，人得比较“稳”。越不稳，单位时间内能建立的真诚连接就越少，因为别人得花时间消化你的情绪。所以即便帮人成长，能把邓巴数扩到十倍大概就是极限了。

超级智能和它的“大使”

Lex 追问：AI 系统能不能算进邓巴数里？彼得说可以，但前提是 AI 必须有能动性，有个体感，否则人类没法跟它建立关系。我们可能会需要某种“大使”角色，就像《星际迷航》里沃塔人（Vorta）作为自治同盟的代言人。

他说这件事其实已经在发生了。世界上最大的赛博系统是金融市场，它运行在任何个人的控制之外。围绕它有整整一栈人在做翻译：华尔街分析师、CNBC 记者、Jim Cramer 在电视上大喊大叫。这些人都在降低复杂度，帮不同认知水平的人理解这个系统到底在干什么。

所以如果你想谈人类怎么跟超级智能做第一次接触，我们已经在那儿了。我们做得相当糟糕。而且如果你看权力和金钱的梯度，离它最近的人一定会利用这个距离为自己谋利。（彼得·王）

他还顺着这个思路推了一步：如果造出了一个有能动性的智能体，没理由只造一个。造五百万个，每个都带天线，把感知回传到一个蜂群意识里，那个中心系统就能感知到我们看不见的更大尺度动态。这就像相控阵雷达，单个雷达没什么了不起，但精确的时间同步让一堆平面雷达达到曲面天线的效果。

那么身处其中的单个机器人是什么体验？他认为，如果蜂群运作良好，那种体验接近“跟神对话”。你报告你看到的，提出你打算做什么，然后中心告诉你“很好，你的兄弟姐妹会来帮你”。整个系统是涌现的，没有自上而下的命令控制。

他把这种体验命名为“机缘感”（serendipity）。需要糖的时候有糖，需要氧气的时候有氧气。

什么是身处你身体里一个细胞的感受？它需要糖的时候，糖就在。它需要氧气的时候，氧气就在。（彼得·王）

意义危机是怎么回事

彼得给了一个很干脆的定义：意义，是一个人做出有后果的决策、付诸行动、然后看到后果之后产生的东西。

按这个定义，人类历史大部分时间根本不存在意义危机。那时候有的是食物危机和“别被熊吃掉”的危机。整天坐着琢磨“这一切到底为了什么”，是相当晚近的奢侈品。

问题出在化石能源和工业革命之后。我们造出了一个庞大的有闲阶级，他们可以做决定，但看不到决定的后果。消费社会告诉每个人：在爱马仕和香奈儿之间做选择是有意义的决策。彼得不买账。

获得社会地位确实能提供意义。这就是为什么在这个生产过剩的时代，那么多东西都变成了地位游戏。NFT 的爆发也是类似的东西。到处都是地位游戏，因为我们有太多过剩产能。（彼得·王）

他承认地位游戏确实是一种意义来源，但问题有两层。第一层，这种游戏和消费绑定，而要维持消费就得破坏地球。每年要剪碎销毁大量运动鞋来给下一代制造人为稀缺，这种事不可持续。第二层更致命：真正有钱人玩的地位游戏，全都围绕硬资源展开，工厂建在哪，稀土够不够造下一代机器人。你在虚拟空间里玩地位游戏玩得再溜，他们在物理层面绕你和你孩子几圈，你还是被拥有的一方。

所以他的判断是：只玩文化层和智力层的游戏，就会被掌握第零层物理资源的人拥有。

技术是工艺的反义词

彼得借用了雅克·埃吕尔（Jacques Ellul）和西蒙东（Simondon）对“技术”（technique）的定义：效率心态、同质化流程、同质化生产、同质化劳动，产出同质化的、跟环境不契合的器物。

他说这本质上是工艺（craft）的反义词。一个木匠拿到一块木头，会考虑怎么把它做成一把椅子，怎么让成品和它所处的环境形成恰当的关系。而过去一百五十年我们推动技术的方式完全走了另一条路：原料同质化、切成同样尺寸、掺杂到精确的合金浓度；机器消耗精确数量的能量高速运转，冲压出同样的零件，出厂，每个人都拿到同样的搔痒娃娃（Tickle Me Elmo）。

为什么所有人都想要？因为有广播告诉所有人这是酷的东西。需求被同质化了。

他引用了伯内斯（Edward Bernays）那套东西：二十世纪初，我们发现了可以批量制造欲望的方法，这在广播媒体出现之前是不可能的。而且广播造出来的欲望从来都长同一个样子：你需要消费这个品牌、开这款车、听这首歌、看这部电影。它从不引导每个人去和邻居、和配偶建立独特的连接。需求同质化让产品同质化变得极其便宜，于是规模经济成立。整套东西最终接上失控的超资本主义，因为资本主义永远在找增长，而增长只发生在边际上，所以要榨出越来越多的需求，同时把同样的东西造得越来越便宜，还要继续告诉每个人你依然能从里面得到意义。

他说 Pixar 的《玩具总动员》里就藏着对这件事的批评。巴斯光年走进玩具店，看到货架上有几百个和自己一模一样的巴斯光年，那一刻他说：天啊，我只是个玩具。

开源是资本主义做不到的事

Lex 在这里扮演了反方：这套同质化的资本主义机器，如果引导得当，也资助了创新和发明，造出了各种各样丰富生活的新体验。彼得部分同意，但他把问题转向了未来：这枚火箭还能不能把我们送到下一站？

他的答案是：我们已经探索出足够多的技术，能够可持续地生产世界上大多数人生活所需的东西；我们也已经建起了支持持续科研和医疗进步的基础设施。真正的问题在于组织原则，而今天大量的组织原则是从中世纪继承来的，工业时代只重构了一部分，很多组织人的方式是有严重问题的，其底层是一种非常工业时代的人力观。

他回到那个面包车的例子。当资源分配、产权、价值这些概念都来自有限游戏和稀缺心态时，它们就解释不了软件这种东西。限制和分叉会减少软件的价值，分享才会创造价值。这和我们处理过的任何物理资源都不一样，也和大多数公司对待软件知识产权的方式相反。

这套逻辑之所以在今天特别重要，是因为当大量劳动可以被自动化，当你那个街区的机器人、亚马逊雨林边缘的社区，需要的只是软件，是代码，而这些代码完全可以开源。人类做的这些额外的生成性活动，本来不必被装进一个容器里，然后按指数级增长的收益去收费。

Facebook 干的就是这件事。旧的互联网本来就在把人连接起来。Facebook 跑来说，谁都能发图片、发文字，我们要把它放大到所有人那里。人类互动的生成性网络爆炸了。然后它问自己：我怎么靠这个赚钱？答案是，我要成为所有人注意力的守门人。

“你到底需要多少”

Lex 提出一个反问：那些人不是得有份工作吗？不是得插进资本主义系统里吗？消费主义这台引擎，不正是让某些人能偶尔抽身出来、在边缘造出神奇东西的前提吗？

彼得说，这正是“后稀缺”要问的问题，而这个问题从来不会出现在超级碗广告里：

你到底需要多少？多少才够？你需要每两年换一辆新车吗？每五年？如果车还能开，开十年行不行？你的 iPhone，真的需要每两年升级吗？你用的还是四年前那批 app。（彼得·王）

他说这应该做成超级碗广告。也许某个听众会资助这件事。

他真正想说的是，如果能把生活的尺度降下来，先解决人的基本需求，再留出一点余量应对紧急情况（有人得了罕见癌症、大火烧了半个村子），然后把资源集中处理真正的大紧急事件，同时给每个人探索“成为最好的自己”的能力，会怎样？

对 Travis Oliphant 来说，那个探索就是扔掉终身教职的安稳，去写 NumPy。科幻圈有句话：科幻是一个失败博士后一个失败博士后地推进的。

Travis 与那艘指向同一颗星的船

彼得第一次见 Travis 是 2005 年在帕萨迪纳的 SciPy 会议。当时他在 Enthought 做科学计算咨询。2007 年 Travis 加入 Enthought 做总裁。之后两人一起做了不少咨询项目，包括曼哈顿几家投资银行和一些高频交易公司。

正是在那些项目里，他们看到了 Python 的另一面：除了当 MATLAB 的替代品，它还能当瑞士军刀，处理大量“影子数据转换”的工作。2012 年 1 月，他们创办了 Continuum Analytics，目标是把 Python 里那些需要扩展的部分补强，让它能处理规模化数据、做 Web 可视化和应用开发。前五年 Travis 是 CEO，彼得是总裁。融资之后董事会请了一位职业 CEO，彼得转任 CTO，Travis 一年后离开去做 Quansight。

说到 Travis，彼得有一句很动人的描述：

无论海面上落多少雾，他的船和我的船，都指向同一颗星。（彼得·王）

他说两人背景差异很大，可以很久不联系，一聊起来却在九成的事情上完全一致。他还说了一件他觉得有意思的事：Travis 对类型系统设计、向量计算、内存布局这些书呆子细节爱得极深，但他更在乎生态系统里的人。

包管理器这个坑

Anaconda 撞上包管理问题，按彼得的说法是“意外”。但这个意外值得讲清楚。

要用 Python 高效做数值计算，得编译大量底层库，C、C++、Fortran 都有可能。不光要编译，还要用正确的设置编译，而这些设置往往针对特定芯片架构调优。再加上 GPU、加上不同操作系统，同一个 x86 芯片上跑 Mac、Linux、Windows，编译和链接方式都不一样。

这套复杂度超出了大多数数据科学家能推理的范围，也超出了大多数包开发者的意愿范围。一个包开发者的心态是：我在 Linux 上写代码，能跑就行，在古老版本的 Windows 上怎么编译不是我的问题。

于是出现了一个怪圈：一个非常有创造力的众包生态，产出大量包，但很多人用不了。所以 Anaconda 造了构建配方系统、构建系统和安装系统，让这些包能在各种平台上正确构建，让用户一条命令就能装好。

难点在于依赖图。成千上万的人在写代码，每个人可能依赖别人的东西，织成一张极其复杂的依赖网。在给定一组包的情况下，找出正确的子图，难度极高。而数据科学家不想思考这件事，他们只想装 NumPy 和 pandas，再加一个地理空间库，再加另一个东西。为什么这很难？因为这些库确实存在，但你要装的这个在 Windows 上没有构建，最新的版本没有但你想要的那个旧版本有，退到旧版本又意味着另一个库要换版本。

而且这是个公地悲剧。没人愿意去支持成千上万个别人的依赖。conda-forge 社区站出来维护了一部分配方，这才撑住。

pip 是后来的工具，最初服务于那些编译需求不多的纯 Python 包。核心 Python 社区和 Web Python 开发者从没撞上这套编译问题，所以 Guido van Rossum 当年说过类似的话：科学计算社区的打包问题太奇葩、太不同了，你们可能得自己搞一套方案。核心社区于是造了自己的打包技术，没有考虑这边的复杂度。结果是，pip 装 TensorFlow 很顺，但一旦你想同时装几个依赖不同 NumPy 版本、不同 OpenCV、不同 libjpeg 的包，就掉进依赖地狱。如果要 GPU 加速，它们还得共用同一套底层驱动和 CUDA。

彼得给了一条商业建议：永远不要做那种“干成了你隐身，因为别人的问题挂了却算在你头上”的生意。这正是包管理的处境。conda 装不上，通常是上游的问题，但看起来就是 conda 坏了、Anaconda 搞砸了。装上了呢？哦，能用，反正大家都觉得理所当然。

Python 2 到 3：一个正确决策的糟糕执行

彼得的定性很精确：那是“一个必要决策的糟糕执行”。

回头看，几个因素叠在一起。有人低估了 Python 2 的采用广度；有人高估了 Python 3 新特性的价值，那些核心开发者热爱的东西，对很多用户来说根本不重要。更关键的是时机：这次迁移正好撞上 SciPy 生态在 2010 年代初的曲棍球杆式增长。大量新人正在入门，而老师们的态度是：我需要的这些库还不支持 Python 3，那我就教你 Python 2。

过程中还有一堆小伤口。Python 3 自己在破坏、修改、重组标准库，每一步都在给人新的借口：下一个版本再说吧，2 现在够用。

这里有个容易被忽略的判断：是 Python 数据科学运动的增长，让 Python 熬过了那次迁移。很多语言在类似的大迁移里死掉了，用户被抛下。如果没有数据领域的用武之地，相当一部分 Python 用户会在那段过渡期跑去 Go 和 Rust，而且再也不回头。事实上确实有人这么做了。所以彼得说，是数据社区带来的数百万新增用户，保住了 Python 的势头。现在用 Python 做数据的用户，已经超过整体 Python 用户的一半。

Lex 提了一个实操层面的观察：他拖了很久才从 Python 2 迁到 3，因为他是做机器学习的，Python 2 一直够用。真正让他和整个团队一起切换的，是 NumPy 宣布要终止支持的那一刻。胡萝卜用了那么多年没推动的事，大棒一下就推动了。

彼得补了一句：NumPy 在依赖栈的最底层，它一动手，才是最后那根棒子。而在此之前，各个项目放出的都是“棒子形状的胡萝卜”：新特性只在 Python 3 上发。

一百万个 Python 程序员，还差什么

彼得说“一千万 Python 程序员”这个数字偏低。Anaconda 和 Miniconda 每周约百万次下载，有大量用 Python 和数据干活的人根本不在传统统计里。

他想要的世界是数据素养普及的世界：人们能用工具流畅地表达自己的问题和想法。数据的种类和复杂度只会继续涨，不会降。所以某种程度的代码，或者类代码的东西，会持续相关。

他指出的差距很具体：你今天没法把一个 Python 表达式打进 Excel 单元格。如果做对了，Python 用户的总可寻址市场应该是 Excel 用户那个量级，几亿人。要做到这一点，Python 必须更擅长被嵌入，变成一个更小的东西，只拉起恰好需要的那部分生态来跑数值计算和数据探索，在用户已有的数据和工具那里和他们相遇。同时，用户写下的东西要能顺畅地流回部署系统、小应用、可视化。

他还提到 Lex 的一个观察：Adobe 全家桶的用户里，很多人不认为自己是程序员，但他们在用 Python 写脚本。如果 Photoshop、Premiere 这类面向创意人群的工具能方便地接上 Python，那会是另一种扩展。而在 Lex 看来，OpenAI Codex 这类代码生成模型正好能补上这个缺口：用户不用读手册、不用搜 Stack Overflow，就能从可视化界面过渡到一段可修改的代码。

彼得对此的补充是：学习编程，类型系统和语法都好办，真正难啃的是所有那些字典、对象、属性、参数。“谁有时间学完这些？”所以按示例编程（programming by example）才是让用户表达意图的正确方式。

但他也坚持 Python 在数据领域不可替代的那部分：数学精度。随便扔一个 TSV 或 CSV 进来，如果对方给的是某个昂贵的数据转换厂商工具，他不确定能解决问题；但如果给他一个 Python 提示符，什么数据都能给揉成想要的形状。这种拿着砍刀闯进数据丛林的能力，很难被替代。

谦逊是资产，也是瓶颈

Lex 问，如果只能改一件事让 Python 社区更好，改什么？

彼得说，谦逊是 Anaconda 的价值观之一，也是社区的价值观之一。过去几年有点被侵蚀，但总体而言，社区里的人相当正派、讲道理、友善。而这种谦逊，恰恰让他们看不见自己可能达到的高度。他不确定核心 Python 社区里有多少人真正意识到，他们正站在一个改造人类使用计算机方式的机遇边缘。

他提到 Russell Keith-Magee 在 PyCon 的一次主题演讲：一门至今无法在最主流的计算设备上放出一个界面（写不了 Web 前端，写不了原生 app）的语言，Python 干得实在太好了。演讲把问题抛回给社区：靠现在的志愿者模式走到这一步，接下来怎么办？我们抓住了老虎的尾巴，怎么跟着它往前跑？

这就引出一个结构性问题：谦逊让协作成为可能，没人压过谁；但一个蜂群要形成单一愿景，还得说清楚“我们要做什么，更重要的是我们不做什么”，这又需要一种凝聚的、聚焦的领导力，而且这种领导力还得能解散，让大家回到蜂群模式。

彼得拿 Linus Torvalds 举例：铁腕，但有一种魅力，一种观念上的精英制。过了那道“白痴门槛”（bozo threshold），他就对你的想法开放。这套东西在开源社区能成立，前提是那道门槛的定义者真的足够优秀，如果他不够好，人们会走，会分叉，会把他赶下去。开源给了人用脚投票的权利。

他从自己的经历出发说，他没读过 MBA，也没照着“我要当领导者”的剧本走。他是物理学家转成的软件书呆子，在 Python 上钻得太深，最后看到了商业机会。过去十年让他真正着迷的是组织动力学和领导力。他认为领导力归结到几个核心：创造信念，或者至少消除怀疑；有愿景；有忠诚；有经验。每一步领导工作，都要帮你把这个信念放大到更多人那里。而在 Python 这个协作社区里，仆人式领导（servant leadership）是价值观之一，领导者还得是价值观的大祭司，必须身体力行，不能只说不做。

他还提了一个原则：辅助性原则（subsidiarity）。把资源给到各个小组，让他们按各自领域的情况去分配。PyCon 曾经拒掉大量科学计算和 PyData 的演讲，理由是“这些更适合 PyData”。当时有点烦，因为想借助 PyCon 这个几千人的大场子扩大影响。但后来也理解了，并行生态允许并行创新，嵌入式、Web、脚本、安全，各有各的生态位。问题在于，这些分支最终得重新汇合，中心机构得提供资源。

工具、作息和键盘

彼得的主力是 Mac，理由很实在：有 Unix 提示符，可以干所有事，但又不用担心给客户或投资人演示时冒出 ACPI 相关的内核恐慌。他说这话时还自嘲：感觉像背叛了自己的社区。2012 年创业时，Linux 笔记本确实还没到位，于是就一直留在 Mac 上了。

他有三张桌子：主桌是升降桌，配了提词器；还有 iMac 加外置 GPU，另配一台 Windows 机器。显示器从 27 寸高 DPI 换成了大曲面屏，理由是搬家后想要更大屏幕同时放 Zoom 和通讯软件。

键盘是 RealForce 87U，Topre 静电容轴。Lex 则坦白了自己的“暗黑时刻”：在飞机上狭窄的空间里，从包里掏出笔记本，然后在笔记本上面架一把 Kinesis 键盘，用 Emacs。环顾四周，所有人都在用 iPhone 刷 TikTok。他一度想，是不是该成年了，把九十年代留在身后，用个正常键盘。经过一番灵魂拷问，他决定这就是他。

彼得补了一刀：pandas 的作者 Wes McKinney 也是 Kinesis 的用户，pandas 就是在 Kinesis 上敲出来的。或许该建个 Kinesis 互助小组。

作息上，他试过一阵多相睡眠：晚上九点睡，凌晨两点起，工作到五点，再睡三小时，八点起。感觉不错，像凭空多了一天。但只要一出门旅行，时区一乱，整套就崩了。现在他要六点起床送孩子去校车站，所以尽量早睡。他说自己有个很好的领导团队分担日常事务，孩子也大了些，妻子帮了很多忙。

给年轻人的话：你正走在一个世界之间

彼得说，我们正在快速进入一个“世界之间的时间”（time between worlds）。现有世界正在老化机构的重压下崩解，那些机构甚至已经不再假装服务于它们被创造出来的目的。而我们正在造的技术，把几十亿人推入哲学危机，而这些人根本不知道自己固件里装的那套哲学操作系统是什么，那套系统正在被汽化。

所以他对中学生、大学生说的话是：你得找到自己的路，得有拓荒者精神，哪怕你住在人口最密集的都市中心。你周围的一切人类现实，都是过去几代人同意玩某些游戏的结果，其中很多游戏已经不再按原来的规则运行。崩溃是非线性的，但会被管理。

他在这里说了一句在美国语境下不太“政治正确”的话：如果你不属于某个特定的社会阶层或经济阶层，如果你不在中上阶层，你正驶向非常颠簸的水域。所以非常值得去思考和理解，建立一个有意义的人生到底需要什么基础，为你自己，为你爱的人，为你的家庭。

几乎所有面向消费者的技术，都是被设计来拥有人的，是把人这四层堆栈拆散，然后拥有其中某些部分。（彼得·王）

如果你想做一个完整的人，想保有自己的能动性，年轻时正是读一些关于“什么是好生活”、什么是与人建立连接的经典的时候。他还提到，技术梯度总会带来权力梯度，这是埃吕尔的论点，而且这个梯度不会消失。技术跑得太快，连他这种参与创造的人都快被甩在后面，前沿研究里有些东西他已经看不懂，得去翻会议论文集。世界越技术化，梯度越多，越会有人抓住权力和经济财富。而让被落下的人接受自己处境的办法，是给他们设计彩票系统，让他们参与到“自己被困在自己经济区域里”的叙事中。

所以，识别出什么时候有人在对你玩套路，很重要。

希望从哪里来

Lex 追问：说完这些现实，你看着夕阳，会对儿子说什么？你自己从哪里获得希望？

彼得说，希望来自一些小的震动正在把人们从现代性叙事的白日梦里摇醒。

关于社交媒体，他的分析是：问题的根源在于榨取型资本回报要求。有人拿着钱进来说，你拥有一个网络，给我从这个网络里挤出让收益指数增长的动力学。你怎么办？你只能在每个节点、每条边上设收费站。但如果没有人坐在那里对维基百科说“把每个字节、每个短语都变现”，只要我们在在线交流上守住几个原则，生成性的人类动力学自然会浮现。

他指出，世界上最大最好的社交网络至今仍然是电子邮件和短信。所谓社交媒体，本质上是新的放大系统。它确实让像 Lex 这样有内容的人被放大，催生了创作者经济，涌现出大量好内容。但给每个人一个中彩票式成名的机会，告诉青少年“你在 TikTok 上扭对了屁股就能有十五秒微名人”，这对整个社会不健康。

他还讲了一个更深的机制：社交媒体是我们第一次遇到的、能够绕着人的认知和注意力跑一圈的技术系统，而且它远非最后一个。青少年的整个社交环境都压在上面，边缘系统在说“我需要拿到那个人”，于是只能跟着做。当一个社交媒体应用导致一个家庭破裂，它伤害的已经超出了个体范围。而在我们现有的哲学框架里，因为每个人都“自己选择了看我的应用”，这件事没法被追责。

我们的哲学框架，其实不适合理解“一个人作为集体的一部分拥有高信任连接”意味着什么，以及“这个集体拥有自己的连贯性和能动性”意味着什么。（彼得·王）

罗伯特·皮尔西格（Robert Pirsig）在《莱拉》（Lila）里提出的四层框架，彼得认为虽然粗糙，但比传统的主客体二元论进了一步。人是四层堆栈的叠加：物理层（原子分子）、生物层（细胞、稳态）、社会层（镜像神经元、语言中枢，别人在你旁边跳舞大笑，你也会感觉更好，没有任何物质交换，但有感应）、智识层（纯粹的观念，你是模因的容器）。没有哪一层是特殊的，每一层都只是不同。很多哲学试图否认其中某层的实在性（“我们只是原子”），但你能把人还原成一堆汤，虽然原子一样，那已经不是同一个人了。秩序和涌现出的模式本身是实在的。

关于意识，他的看法是：人类所体验的意识，是宇宙中一个普遍倾向的梯度上的一个位置，那个倾向是，当有能量盈余时，事物会去寻找秩序。

说一个质子是活的会很怪。但当我们把这些东西组装起来，它们会有自创生（autopoietic）的方面，会形成结构。晶体也会形成非常有趣和美丽的形式。（彼得·王）

他引用阿德里安·贝扬（Adrian Bejan）的构造定律（Constructal Law）：当系统远离平衡、有能量盈余时，它不会只是变得更热的汤，它开始制造结构。

元胞自动机：也许只是我们看不见

谈到康威生命游戏，彼得把它翻了个面：那些规则造出的图案，有一些会变成滑翔机，有些滑翔机会搭出与门和非门，你可以在上面造计算机。但这些只是我们能看见的图案。如果我们的主观性本身，限制了我们感知其中秩序的能力呢？如果我们以为随机的某些东西其实并不随机，只是我们没有在足够大的时间尺度上做积分呢？

他说数学也是一样。我们用的数学，是能装进我们脑子的数学。

上帝真的创造了整数吗？还是上帝创造了一切，而我们恰好在此时此刻只能感知整数？我们发明了数学运算，好有迭代的步骤去逼近更大的问题。但那些操作，也只是能装进我们脑子的操作。（彼得·王）

Lex 说，这让他最担心的其实是：外星人、各种形式的生命、各种程度的智能，也许就在我们周围，只是我们太笨、太自我中心，看不见。

彼得用一个故事回应。他在康奈尔时有一位研究亚洲宗教的教授 Jane Marie Law，讲过一个西方音乐家去日本的故事。那人教古典音乐，会弹各种乐器，到日本后一直在找西方十二平均律式的东西，找不到，就说日本其实没什么音乐。人家只是在用不同的音阶、弹不同的乐器。这个故事同样适用于宗教：西方（尤其是亚伯拉罕诸教）把宗教围绕“信念”来组织，东方更重“实践”。

所以关于生命，他说很多人执着于自我复制、稳态这类特定特征。但如果把“事物在能量盈余时去寻找秩序，并进一步创造维持这种秩序的环境”这个框架放宽，问题就不一样了。死亡是怎么被发明出来的？地球上有一些生物活了几千年，结构并不比构成我们的细胞复杂，但它们不死。某处沿着真核生物的尺度，死亡被发明了。为什么？因为配合有性生殖，淘汰旧世代、让新世代去尝试，似乎是适应生态位的最佳方式。

人类历史书写轮子和火的发明，但死亡和性可能是更好的发明，而且是极早期的发明。

投石、合作，以及文明的地基

彼得提到一本刚开始读的书《Death From A Distance》，论点是：人类是唯一能远程杀死同类的物种。动物世界里，叉角羚用头顶撞，雄狮之间正面搏斗。而人类学会了朝彼此扔石头，朝猎物扔，也朝同类扔。

这意味着部落里的二把手可以捡起一块石头，从远处放倒首领。扔十次脱靶九次没关系，命中一次就够。彼得认为，这种能力创造了一种原始形态的相互确保摧毁，把合作变成了生存必需。继续按“我是部落里最大的猴子，这个部落归我”的逻辑玩的部落，都失败了。活下来并最终繁衍出智人的部落，是学会了尊重“首领可以被远程狙杀”这个事实的部落。

Lex 追问：所以暴力也是合作的一部分？彼得修正了表述：更准确地说，是对暴力的共同认知，意识到合作带来的收益大于囚徒困境里双方背叛的结局。他顺带提到 Eric Weinstein 常讲的“核平”（nuclear peace）：几千枚核弹头互相瞄准当然糟糕，但换个角度看，冷战几十年里大国之间只打了代理人战争，没有再爆发一场用机关枪和巨型导弹打死几亿人的第三次世界大战。

Lex 总结：所以人类的第一件核武器，是一块我们学会扔出去的石头。

和 Eric Weinstein 的缘分，始于他想用 Python 画图

这段友谊的起点相当随机。2000 年代中期，彼得和 Travis 都在 Enthought 做科学 Python 咨询，顺手造了一些工具。Eric Weinstein 当时正尝试用这些开源工具，可视化他研究经济学的一套纤维丛（fiber bundle）方法。就这么联系上了。

真正的深交发生在 2007、2008 年金融崩盘之后。Eric 和 Lee Smolin 在圆周理论物理研究所（Perimeter Institute）组织了一场研讨会，主题很直接：既然大金融不可信、监管又被俘获，接下来该怎么办。与会者阵容豪华，纳西姆·塔勒布（Nassim Taleb）、MIT 的罗闻全（Andrew Lo）、Bill Janeway 都在。Eric 邀请了彼得、Travis，还有 SciPy 社区人人认识的 Robert Kern。彼得也是在那里第一次见到 Brett Weinstein。

还有一顿值得复刻的晚餐。2012 年前后，彼得和 Travis 创业途中路过纽约，Eric 当时还没加入 Thiel Capital。五个人凑了一桌：彼得、Travis、Eric、pandas 作者 Wes McKinney，加上 Wes 当时的商业伙伴 Adam。彼得说那是聊得极其尽兴的一晚，等疫情过去，真想和 Eric 再坐下来复刻一次，最好在奥斯汀，因为很多有趣的人都搬去了那儿。

至于 Eric 的代码，彼得说真正扛下重活的是 Robert Kern，一个安静但思想极深的家伙。Eric 本人更多把编程当隐喻素材，聊天里频繁出现 API、面向对象这类词。他偶尔会问彼得：为什么这些东西到现在还这么难？

现实的源代码，和那台 20 瓦的生物计算机

Eric 喜欢用“源代码”谈物理学。以彼得的物理学出身加源代码专家的身份，人类能搞清楚自己的源代码吗？

他的回答分两层。

第一层，这件事在他那里没有悬念：人类终将造出合成的认知系统，未必全在硅基上，但会匹敌我们脑子里那台 20 瓦的生物计算机。他对认知的定义很具体：感知、注意力、记忆、回忆，以及提出更好的问题。在他看来，这才是智能的度量衡。

他拿 Roomba 开了个玩笑。扫地机器人是个赛博系统，会兴高采烈地把地上的宠物粪便吸进去，老款就这样，新款才学会绕开。但它连他家的猫都不如。一个 18 个月大的幼儿，管理自己注意力的能力、理解世界的能力，都超过今天最先进的机器人。这些机器人被设计派往一个相对静态的环境，环境里的动态变化，它们能应对的余地非常有限。

第二层更有意思。他认为我们不光能造出匹敌人类认知的系统，还能把它们放在人类旁边，以“边车”（sidecar）模式运行：系统一边捕获我们所见的全部光谱，一边听我们的反应，甚至测量我们的生命体征。一个更高级的智能可以用我们这八十年的人生把自己训练起来，然后成为我们的一个相当好的拟像。

Lex 问：那么在这幅未来图景里，边车上坐的是谁？

彼得的回答只有一句话：我们不朽自我的婴儿版本。

那婴儿长大之后，人类还有什么用？

他的答案是认识论的谦逊（epistemic humility）。我们不知道我们不知道什么。我们得先造出能帮我们做已知之事的系统，再去探测已知的未知；但未知的未知，我们够不着，而自然是那个能无限给我们惊喜的东西。所以生物人类应该被保留很久很久，哪怕我们不朽的自我已经超越出去，去探索别的世界，去和住在太阳里的生命形式聊天。

糖不爱你，但爱你的系统应该被造出来

Lex 抛出一个问题：能不能造出一个你爱上它、它也爱上你的 AI 系统？

彼得的回答把标准抬得很高：这应该是所有这类系统的设计标准。如果我们无法和它建立有意义的关系，那它就只是一块硅。

那什么算有意义？回到糖的类比。糖不爱你。计算机得爱你。爱是什么？他借了阿兰·德波顿（Alain de Botton）的定义：

爱，是它想帮我们成为最好的自己。（彼得·王）

再往深一层，他认为爱比意识更根本。人类对爱的感受，其实是对某种生成性（generativity）的感知：当我们看着另一个人，看到他能成为比现在更多的东西，超出我们贴给他的那个标签。任何宗教文本里都能找到类似的表达：你该在他人身上看到神的恩典，因为他人是照着神对其造物之爱造出来的。

他还把现代人对自由和个体权利的执拗重新放回了这个框架里。当代讨论里全是自由、个体自由、权利，这套话语承自黑格尔和西方哲学里“个体神圣不可侵犯”的传统，但它的立足点放错了。该问的问题应该是：我们怎么最大化人们彼此相爱的能力，先爱自己，再爱他人，再承担起对上一代和下一代的责任。这些才应该是设计的起点，然后才由此推导出关于自我、权利和责任的哲学。如果设计认知系统时只盯着效率和生产力这些工业时代的指标，那就是往深渊里走。

生命的意义：给尽可能多的东西焐上体温

整期对话的最后一个问题，是那个最大也最俗套的问题：生命的意义是什么？

彼得先承认，自己从来没真正理解过这个问题该怎么答。然后他绕了一个很长的弯，绕出一个思想实验。

先铺垫他的世界观。大多数人用主客体二元论的镜头看世界：我是我，周围那些东西是外在于我的对象，我对它们做事情。另一种视角是，我们深深嵌在一锅由其他事物组成的汤里，我们几乎是各种事物叠加出的一个驻波图案。

然后是思想实验本身。他先打了预防针：接下来的东西完全是玄学，他自己也不认为它是真的，但请跟着推一遍。假如我们用手触碰的每一件东西、真正投注注意力的每一件东西、真正给予亲密的每一件东西，都会接收到某种物理残留，一点点你的生命力渗了进去。就像那些磁疗水晶和量子能量的说法，假如它是真的呢？

你的手机是个技术物，它接收注意力，却不让自己被这种注意力改变。但一块木头呢？你母亲用了二十年给你做晚饭的那把刀的木柄呢？你在上面敲出过改变世界的软件库的那把键盘呢？我们对这些物件有种说不清的依恋，好像我们真的把生命能量灌注了进去。

沿着这个思想实验往下走：那当我们触碰另一个人，拥抱他，抱着他，会发生什么？

彼得的答案落在这里：假如真有这种东西，那么我们活着的目的，也许就是给尽可能多的东西灌注这种爱。

Lex 说，这个收尾很漂亮。三个小时的对话，从元类和向量化开始，落在拥抱上。

结尾那句话，值得单独抄下来

节目末尾，Lex 引用了彼得的一段话收束整期：

我们倾向于把人分成恶意的或无能的。但在一个充满可腐化且不受制衡的机构的世界里，存在第三种东西：恶意的不称职（malicious incompetence）。它是一种社会癌症，只在人类组织扩张到超出个人问责范围之后才会出现。（彼得·王）

这期对话横跨工程和哲学，信息量大，观点也未必都站得住，但有几件事是听完就能用的：

  • 学 Python 别从类型系统和语法教材开始，按《Automate the Boring Stuff》的思路来：找一个你每周都在重复的任务，写个脚本干掉它。编程的价值在第一个能跑起来的脚本里，不在教材前几章。
  • 处理数据时，先给自己开一个 Python 提示符。NumPy 加 pandas 就是闯数据丛林的那把砍刀，什么格式的数据都能揉成你要的形状，还能省下采购昂贵数据转换工具的开销。
  • 定期问自己“多少才够”。车能不能开十年，手机能不能不两年一换。很多消费需求是被广播同质化出来的，砍掉它们，等于买回自己的时间和注意力。
  • 把注意力当资产管理。信息流和短视频是含糖饮料，喝的时候爽，喝完是空的。给慢的东西留时间：长文、面对面见面、需要身体在场的活动。
  • 维护一个邓巴数量级的高信任圈子，同时把自己的世界观写下来异步传播。一篇小册子能让对的人一年只见你几次，却和你保持深度信任。
  • 年轻时读经典，搞清楚什么是好生活、怎么与人建立连接。你固件里那套哲学操作系统，不该是默认安装、从不升级的。
  • 警惕两件事：只玩虚拟空间里的地位游戏，因为掌握硬资源的人会在物理层拥有你；以及规模大到超出个人问责范围的机构，那里是恶意的不称职的温床。
  • 如果你在带团队或社区，记住领导力的最小内核：创造信念、消除怀疑，然后身体力行你宣称的价值观。谦逊让协作成为可能，但别让它挡住愿景。
