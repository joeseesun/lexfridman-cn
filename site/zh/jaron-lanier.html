杰伦·拉尼尔（Jaron Lanier）有一个习惯：每当有人问他“我们会不会有一天在虚拟世界里度过一生”，他都会讲同一个故事。他说，虚拟现实里最珍贵的时刻，是你摘下头显的那一瞬间。你的感官被重新校准，你像新生儿一样重新看见物理世界，发现它原来如此奇怪、脆弱、不可思议。

他管这个叫“过渡”。而且他坚持认为，过渡比模拟本身更有价值。

这个人在1980年代就做出了世界上第一个外科手术模拟器，当时他和斯坦福医学院的乔·罗森（Joe Rosen）医生合作。他说，外科医生从模拟的假解剖结构走到真实病人面前时，会突然被“唤醒”。那个从假到真的跳跃，比在假世界里练一百遍手术更有冲击力。

拉尼尔是虚拟现实这个领域的创始人，但他可能是最不沉迷虚拟世界的VR先驱。这个矛盾贯穿了整场对话，也贯穿了他整个思想体系：他造工具，但他始终警惕工具对使用者的塑造。

软件是历史的奴隶，物理世界不是

拉尼尔对软件的评价毫不客气。他说软件是“很糟糕的东西”，永远被自己的历史、自己的遗留问题绑架，永远杂乱、随意、充满任意性。跟软件打交道会激发人身上一种“书呆子人格”，而他自己并不喜欢那种人格。

物理世界完全不同。它不是任何人设计的，也不是任何人能完全理解的。拉尼尔说，当你把一个虚拟物体放在一棵真树旁边，真树会突然“跳出来”变得惊人：它是交互式的，它在细微地持续变化，它需要你集中注意力才能察觉。而虚拟物体反而让你学会了如何注意真树。

这就是他反复强调的那个观点：媒介技术送出的最大礼物，是让人看见媒介自身的缺陷，从而更欣赏现实。

他举了一连串历史例子。早年有同行评审论文证明，用钢丝录音机在幕布后播放歌剧演员的录音，听众无法分辨真假。今天我们会觉得那种录音糟糕得离谱。1930年代纽约到华盛顿之间有一次极其粗糙的视频会议演示，当时的人觉得完全逼真、无法分辨，今天看来画质惨不忍睹。美国内战时期，有流动摄影师收集长相接近某些原型的人的照片，人们买一张长得像自己亲人的照片来寄托思念，因为拍照本身不可想象，雇画师又太贵。

“也许摄影最大的礼物，是我们能看见照片中的瑕疵，从而更欣赏现实。也许录音最大的礼物，是我们现在能把那个歌剧演员和钢丝录音机里的她区分开来。”

拉尼尔用这些例子反驳一种隐含的假设：人的感知能力是固定的。他说人一直在学习、演化、自我编程、适应变化。因此，那个经典问题“技术会不会发展到我们无法分辨真假”，其实问错了。因为“分辨能力”本身是变量，不是常量。

宇宙是不是计算机，这是个没意义的问题

拉尼尔对“我们是否生活在模拟中”这个流行话题有自己的态度。他说，如果你问“宇宙是不是某种计算机”，那答案只能是“是”，因为如果它不是，它就不会遵循一致的原则，就不会是可理解的。我们能用技术编程它，说明它在某种意义上就是计算机。

但接下来那一步是危险的：从“它是某种计算机”跳到“我们知道它是哪种计算机”，甚至“它是一台通用图灵机”。拉尼尔称图灵机为“挑逗者”。他说，图灵机的通用性建立在无限聪明的程序员、无限时间、无限内存、无限时钟速度之上，而这些在现实中都不存在。所以图灵机在实践中根本不通用，它只是特定约束条件下的一种特定机器。

“把宇宙理解为一台图灵机，可能是愚蠢的做法。因为图灵机需要一个外部时钟、一个观察者、有输入和输出。它暗示着一个更大的上下文，否则它根本无法被定义。你没法用图灵机连贯地谈论宇宙。”

他把这个话题引向了一个更深的方法论问题。他说，很多终极问题的提问方式本身就藏着一个错误假设：人的感知能力是固定的，所以“逼真到什么程度人就分辨不出来”这种问题才有意义。但真实情况是，人一直在变。

他顺便批评了那种沉溺于“我们是否在模拟中”的人。他说他希望这些人退一步，想想自己的动机到底是什么，想想自己到底在说什么。这类框架性大问题的危险在于，它让人假装自己知道的比实际多。

自由就是永久的烦恼

对话进行到比特币和加密货币时，拉尼尔的立场很清晰。他长期倡导某种形式的数字货币，但比特币白皮书出现时，他说自己的心“沉了下去”。因为他看到的是一群人用极其精巧的分布式安全机制，去重建金本位。在他看来这既复古又低效，从经济角度毫无用处。

更让他不满的是，用无边界规模的计算低效来充当安全机制，是对大气层的犯罪。他说这在第一版论文出现时大家就知道了，很多人当时就说这东西是个碳灾难。

他承认社区里有人在认真思考更好的方案，比如维塔利克·布特林（Vitalik Buterin）。但他对加密货币的实际效果持怀疑态度。他说比特币所有权很集中，有大量身份不明的早期巨鲸，有证据表明其中不少不是你想支持的那种人。而比特币交易整体上支持犯罪多于支持生产力。

“我一直在密切关注它。我没有见过一个它创造经济增长的例子。”

他更在意的是背后的动机。他说，那种“政府是问题”的执念，本质上是逃避政治。他给出了一个他自己很得意的定义：

“关于自由，我的理论是，唯一真实的自由形式是永久的烦恼。烦恼意味着你真的在和别人打交道，因为人是烦人的。永久意味着这种烦恼是可承受的，不会毁灭所有人。所以如果你有永久的烦恼，你就有自由。”

他邀请对方去参加一次伯克利市议会会议，体验一下什么叫“永久的烦恼”。他说，如果你不被别人烦到，你就没有自由，你被困在某个暂时性的幻觉里，早晚会崩塌。

他进一步说，把问题归咎于政府是一种错觉。问题也可能是犯罪团伙、怪异教派、滥用职权的神职人员、失效的基础设施、被污染的水源、崩溃的电网、糟糕的教育系统。只盯着一类问题，其他问题就会冒出来。

但他也承认，他自己成长于苏联，妻子的父亲被送进古拉格，他父亲一方几乎所有亲属都在乌克兰的一场大屠杀中被杀。所以他对政府的看法不是天真的乐观。他的立场是：政府有时确实能做好事，政治是人类不得不彼此打交道的现实。

加密货币给年轻人的希望，是令人心碎的

拉尼尔提到自己和一些早期比特币参与者争论过，他当时就说这东西本质上是庞氏骗局，早期的人比后期的人拿得多，越往后越接近赌博动态。

有人给他一个辩护：赌博让人体验到“希望”，而很多人生活中没有别的希望来源。拉尼尔说这个论点让他觉得心碎。他见过一些投资加密货币的年轻人，那确实是他们第一次感到希望。而他认为这恰恰是问题所在。

“我很抱歉这么说，但从长期看，金钱不会成为深层意义的来源。有足够的钱是好事，但它不该是希望的来源。让我心碎的是，对多少人来说它就是希望的来源。”

他把这称为“病毒式传播的心理学”，或者说“试图把文明建立在网络效应高峰的半随机出现之上”的心理学。他说这种模式行不通，需要把这些高峰削平。

他不相信 AI，只相信算法

整场对话里，拉尼尔最尖锐的部分出现在这里。他直说：

“我不相信 AI。我认为不存在 AI。只有算法，我们制造它们，我们控制它们。它们是工具，不是生物。”

他承认这种说法会冒犯很多人，而且他很清楚这一点。他年轻时的主要导师是马文·明斯基（Marvin Minsky），而明斯基正是“计算机作为生物”这套修辞的主要作者。拉尼尔说自己一直拒绝这套东西，他们为此争论了几十年。他记得最后一次见明斯基时，对方已经非常虚弱，有共同的朋友劝他别跟明斯基争论 AI。他还是去了，明斯基抬头看着他，说：“你准备好争论了吗？”

拉尼尔说，没人能声称自己绝对知道别人或别的东西是否有意识，这完全是信仰问题。他早年把这个概念叫做“同理心之环”。你画一个圈，圈内是更像你的东西，可能有意识，可能值得你的共情和考量；圈外是石头之类的东西。这个圈从根本上建立在信仰之上。

但这个圈不能是纯粹的信仰，它同时是一个务实决定。圈画得太大，你会陷入无能：如果你不想杀死任何细菌，你就没法刷牙。圈画得太小，你会变得残忍。人天生是部落性的、政治性的，总是急于把某些群体踢出圈外。

当被问到“你是不是把 AI 踢出了圈外”时，拉尼尔说，如果你把 AI 纳入圈内，你就剥夺了自己作为优秀工程师或设计师的能力，你立刻陷入无能。所以他的结论是：我们必须让算法从属于我们，对它们保持高度怀疑。

社交媒体真正在做什么

拉尼尔对社交媒体的批评很具体。他说，社交媒体算法依赖反馈循环：给你刺激，看你是否回应。问题在于测量机制极其粗糙，只能捕捉你比较剧烈的反应，而剧烈的反应就是战斗或逃跑反应，就是你被吓到、被激怒、变得好斗或兴奋的反应。这些是古老的“蜥蜴脑”回路。

“所以就在你被卷入互动的时候，你会逐渐变得更多疑、更排外、更好斗。你会变蠢，会变成混蛋。它是慢慢发生的，不是每个人瞬间被转化，但确实会渐进地发生，被钩住的人会被越来越深地拉进这种最糟糕的状态。”

他做过实验。因为 YouTube 规模太大，很难得到统计上可靠的结果，但他和高中的孩子们一起做过很多次。大多数情况下，大约十七八跳之后，你会进入非常怪异、偏执、荒诞的领域。因为那正是算法最奖励的东西，正是因为反馈机制的粗糙。

“我不是说 YouTube 从不推荐好东西。我是说它的根本核心是推崇偏执风格，推崇越来越强的易怒、排外、恐惧、愤怒、自私，推崇人与人之间的分裂。”

他担心的是，如果做大规模公民科学实验，YouTube 会检测到然后改变行为。

他提出了一个他觉得很重要的观察：几乎所有做大的社交媒体平台都有一个蜜月期，那时候它们其实挺甜、挺可爱。Twitter 早年很甜，Snap、TikTok 也是。但随着规模扩大，算法取代了早期用户成为主导力量，偏执风格就开始上升，平台开始变暗。他说 TikTok 最近就经历了这种转变。

GitHub 的毒性和它的秘密

拉尼尔对 GitHub 评价很高。他说 GitHub 的“毒性指数”相对很低，这很有意思。他分析原因：在 GitHub 上，人们有真实的利益攸关。那里流动的是真实的代码、真实被完成的东西，空洞的地位游戏占的比重小得多。一旦你在某件事上有真实利害，你就有动机不去破坏它。

他说，如果一个人在 TikTok 上靠踩别人获得一点关注，他不用付出任何代价。但在 GitHub 上，人们有共同的利益，所以必须得体。

不过他也提出了一个反直觉的警告：如果平台能利用“你有利益攸关”这一点来操纵你，因为你想保住你的利益，那它也能反过来控制你。

数据尊严：两个未来的对比

拉尼尔最完整的建设性提案出现在这里，他称之为“数据尊严”（Data Dignity），之前在一本叫《谁拥有未来》的书里写过早期版本。

他住在伯克利山上。随着气候变化，山火可能烧掉他们的房子甚至要命。谁在保护他们？市政府做了一些事，电力公司勉强算，房产主照顾自己的地产。但还有一层中间层让他着迷：那些在山坡上上下下工作的园丁，很多人没有合法身份，很多人不会说英语，他们彼此合作，确保树木不互相接触，避免火从一块地蔓延到另一块地。这是保护他们安全的一整张小小网络。

他用这群人对比两个未来。

未来一（正在发生的未来）：一辆画着幼儿园涂鸦的奇怪面包车开上山，车上装满了摄像头和各种奇怪设备，观察园丁在做什么。几年后，能爬树的机器人出现，那些园丁失业了。机器人很好，能覆盖更多土地，确实有效。但那些园丁失去了尊严，不知道自己该做什么。有人说，那就发基本收入吧，他们成为国家的被救济者。拉尼尔说，历史上每一次有某个中心化机构发放福利，它都会被某些人夺走，因为太中心化。他见过的每一个共产主义实验都是这样。所以这个未来不稳定，在政治上会是一场灾难。有人会说，那就让算法来发。但人们会夺走算法，会夺取控制权。

未来二（数据尊严）：园丁们看到那辆装满摄像头的面包车，他们说：“机器人要来了。我们要成立数据工会。”加州正好有一个小小的数据工会法律在萌芽。他们说，我们不仅要把数据卖给这家公司，还要让数据比他们直接抓取要好得多。我们要改进它，让机器人更有效，我们要为此感到骄傲。我们要成为被尊重的新专家阶层。

两个未来最大的区别落在人身上，技术层面完全相同。未来二里有更多骄傲、更多主人翁感、更多能动性。而且机器人做的事情也变了：从单纯防止社区烧毁，变成一整群有创造力的社区在思考如何让机器人更好，如何继续赚钱。会出现一波又一波的创造性园艺，会出现新的想法：能不能用这个做气候缓解？能不能做淡水？能不能让食物更健康？

“未来一和未来二有同样的机器人、同样的算法。没有技术差别，只有人的差别。第二个未来，就是数据尊严。”

他描述的经济模型是一个诚实的测量装置。如果它是诚实的，人的收入分布会形成正态分布、钟形曲线。有少数人做得非常好，很多人做得还行。然后经济应该扩张，反映越来越多的创造力和专业技能在网络上流动。这样从系统中拿钱的人比投钱进去的人多，经济逐渐扩张，水涨船高。社会必须支持钟形曲线下方的那一翼，但这不是普遍基本收入，因为如果经济是诚实的，就会有那一翼，必须有一个安全网。

他说，未来会有越来越多的算法和机器人，也会出现越来越多的细分领域。不是每个人都要给园艺机器人提供数据，也不是每个人都要靠 TikTok 视频谋生。但会有很多、很多、很多这样的细分领域演化出来，正是这个庞大的数量，会创造出经济潜力，让社会很大一部分人成为新的创造性阶层。

“TikTok 加 GitHub”的混合未来

拉尼尔想象了一个未来：很多人想靠做 TikTok 舞蹈视频谋生，但大家普遍知道这很难进。不过舞蹈团队的经历和程序员在 GitHub 上协作非常相似。所以未来是 TikTok 和 GitHub 的混合体，人们聚在一起，拥有权利，为回报谈判，加入不同的艺术家协会来缓冲网络效应收益的随机性，因为没人能预知谁会爆红。

他说一个人一生中可能会加入一千个不同的数据工会，甚至一万个。有些只是为了一些琐碎的东西给你一点小钱，比如你为健康研究贡献了数据。但人们会找到自己的路，会找到合适的 GitHub 式社区，在那里发现自己的价值：为未来的算法和机器人提供输入、数据、品味和纠正。

“这是一种对抗蜥蜴脑式融资机制的替代经济系统。它奖励生产力、创造力、被他人感知到的价值。它是一个真正的市场。它不是从中心发放的。不是某个共产主义者在决定谁有价值。它是真实的市场。钱是通过支持这个来赚的，而不是用最廉价的方式抓取人的注意力，而那恰恰是通向蜥蜴脑的方式。”

音乐、母亲与死亡

对话在音乐和死亡这两个话题上变得非常私密。

拉尼尔说音乐“高耸在他之上”，他对自己没有全局视角。他说音乐在某种意义上很简单，你可以说它是人类演化出来协调大脑模式层面的东西。但它同时又有一种“实质性”，一种哲学上不可能存在的实质感。他说自己不知道该怎么处理这一点。

“我在对的时刻听到对的歌时所感受到的理解，跟我在维基百科上读到的任何东西都不可比拟，跟任何我能用语言读到、理解到的东西都不可比拟。音乐确实把我们连接到某种东西。”

他说音乐让他相信泛心论（panpsychism）可能是真的，即宇宙万物都有意识。但他本人不是泛心论者。他说他会骄傲地做一个“对人和猫而言的二元论者”。他说，如果听任何一个试图用二元论解释意识的人讲话，无论是相信灵魂还是相信大脑里有某种特殊东西，你基本上都会说，算了，我还是当泛心论者吧。

谈到母亲时，拉尼尔说母亲是维也纳的钢琴神童，在集中营幸存下来，后来在美国的一场车祸中去世。他仍然通过音乐和她连接。

他回忆自己小时候为母亲学弹贝多芬奏鸣曲，弹得夸张、煽情。对方问，夸张的意思是情感过满吗？拉尼尔说，那时候他以为这是唯一弹贝多芬的方式。他说现在的时尚是弹贝多芬也要稍微阿波罗式一点，但想象中贝多芬自己弹可能不一样。

他说自己一直反对古典音乐的临床式精确。他认为一个伟大的钢琴家应该像是在承受痛苦，真正感受音乐，让它变得凌乱，也许像布鲁斯钢琴家弹布鲁斯那样弹古典音乐。他提到一个很棒的现代主义作曲家波琳·奥利弗罗斯（Pauline Oliveros），他曾在她乐队里弹过一段时间。她说贝多芬是“最糟糕的音乐”，“全是自我”，“把情感变成你的敌人”，“最终都是关于你自己的重要性，而这必然以他人为代价”。拉尼尔说这很有意思，因为他一直把贝多芬当成神一样的人物。

他说他仍然喜欢弹《月光奏鸣曲》，虽然这是陈词滥调。他提到乔恩·巴蒂斯特（Jon Batiste），《科尔伯特秀》的乐队领队，会坐在那里弹爵士，然后突然转到《月光》。巴蒂斯特能找到一种方式弹贝多芬，而且他真的能弹，他在朱利亚德受过训练。有一次在拉尼尔家，巴蒂斯特说，你有贝多芬奏鸣曲的谱子吗？我想找一首我还没弹过的。然后他视奏了整本谱子，完美无缺。拉尼尔说，天哪，我出去吧，我受不了了。

他说巴蒂斯特有一种方式，用同一个人格和哲学从布鲁斯转到贝多芬，这对他非常迷人。巴蒂斯特谈起贝多芬就像在跟一个音乐家对话。而对拉尼尔来说，贝多芬被介绍成一个近乎神一样的人物，这是一种很难对付的艺术压力。

关于死亡的恐惧

拉尼尔写过一篇关于死亡和意识的文章，发表在《意识研究期刊》上。他说当时感兴趣的是，对死亡的恐惧和否认，如何影响不同的意识哲学路径。

他说，一方面，那种感伤的二元论学派，即相信有某种脱离物理大脑的东西、某种灵魂，显然是被一种希望所驱动：无论那是什么，都会在死亡后存活。这是很多世界宗教的核心。另一方面，那些硬核的反面，即“大脑就是计算机，就这样”，实际上被同样方式驱动，论证链条惊人相似：不，大脑是计算机，我会在有生之年搞明白它，把自己上传，然后永远活着。

“在一种有趣的方式上，这是同一回事。”

他注意到那些看起来在性格、文化参照和观念上完全对立的人，实际上惊人地相似。那种硬核的计算主义大脑观，已经变成了中世纪的基督教：有人害怕如果你有错误的想法，你会惹恼未来的超级 AI，它们会回来电击你。这真的又变成了中世纪的基督教。

对方问，如果对死亡的恐惧是核心，它是不是意识的前提条件？拉尼尔说这问题他没法直接回答，需要一次大规模解构。

谈到自己的死亡时，他说他以前无法面对，但随着年龄增长，你会认识死去的人，这些事变得熟悉、变得平常。他还害怕吗？他说当然，但没那么怕了。他说这种变化来自熟悉感，跟洞见或启示无关。他说他相信未来。他有这种乐观：人类，或者地球上生命的整体，这个我们所属的整体，会去往某个地方，有某种价值。

“你不能既相信未来又想永远活着。你必须为未来腾出空间。那种乐观必须带着它自己的谦卑。你必须让自己变小，才能相信未来。所以它以某种有趣的方式安慰我。”

他说乐观需要在某个时刻退场。生活看起来很短，但就这样吧。

意义是个错误的问题

谈到生命的意义时，拉尼尔说“意义”是个有趣的词。我们说出这些东西，好像我们知道它们是什么意思，但其实我们显然不知道。它最终连接到二元论者相信的那种体验感。

他说，当你仰望星空，感受到那种令人敬畏的喜悦，那种奇怪的、也许带一点忧郁的情感混合物，最终的问题就是：我们为什么在这个浩瀚的宇宙里？为什么？

他说自己的冲动是觉得这问题不太对，但走那条路太无聊了，他不想展开。他说，因为我们不知道意义是什么，但他知道那种敬畏感。他在新墨西哥州南部长大，星星非常清晰。他有过一些奇怪的不幸，也有过一些奇怪的幸运。他的一个近邻是白沙导弹靶场光学研究的负责人，年轻时发现了冥王星，名叫克莱德·汤博（Clyde Tombaugh）。汤博教他做望远镜，磨镜片。他父亲小时候也做过望远镜，但汤博的后院望远镜能让很多专业设备相形见绌。他记得汤博会让他过去一起玩，看一个球状星团，你看到的是真实的光子。好的望远镜里，那个物体是真正的三维物体，你能感受到它的浩瀚。他说自己非常幸运，小时候能以那种方式和天空建立连接。

他提到一个想法，他不记得是谁说的：如果早期人类看不到星星，如果地球大气总是多云，我们就不会发展出人类文明。能抬头看见浩瀚宇宙，对文明发展是根本性的。这让他想起阿西莫夫的一个老故事，讲一个星球上的人偶尔才看到天空，结果发现他们身处一个球状星团的中央，到处都是星星。

他说他想到了所有在多云天空下成长的文明。维京人需要一种特殊的衍射云母片来导航，因为他们永远看不到太阳。他们有一种叫“太阳石”的东西，从某个洞穴里发现的，用来衍射光线，对齐太阳的真实位置，因为他们无法用眼睛判断。他说亚马逊人发明了我们的农业，他们可能也常常在多云天空下。

回到意义的问题，拉尼尔说，有时人们会犯一个错误：用一个在某个上下文里定义的问题或思想实验，去解释没有更大上下文的东西。这属于范畴错误。他说，在物理或计算机科学里，很难把宇宙当作图灵机来谈论，因为图灵机有外部时钟、观察者、输入输出，它暗示着一个更大的上下文才能被定义。量子力学也是这样，它有外部时钟，有某种外部上下文，取决于你的解释。

“如果你有一个用外部上下文定义的东西，你就不能用它谈论终极问题，因为显然它不适合这个。意义是在上下文中的，谈论终极意义因此是一个范畴错误。它不是一个可解决的思想方式。它可能是一种在体验上或美学上有价值的思想方式，因为它令人敬畏，但试图分析地对待它是不合理的。”

对方问，也许这正是音乐和诗歌能做的？拉尼尔说，也许吧。音乐确实逃脱了任何特定上下文，至少他是这么感觉的。但他不确定。他说，这又是那个疯狂的艺术家在说话，不是科学家。

给年轻人的建议

被问到给年轻人的建议时，拉尼尔先说了实话：定义他的时刻不是好时刻，往往是可怕的时刻。他母亲的死，在世贸中心底下经历9·11袭击，这些才是对他影响最大的事。他说这就是给年轻人建议最难的地方，他们必须自己学教训，而教训来得不容易。一个避免艰难教训的世界会是一个愚蠢的世界。

他说他不想让年轻人经历一切，他们值得有一个愉快的天真期。但他还是给了几条建议。

第一条：试着真正关注你根本上在感受什么，你对世界的感知是什么，你的直觉是什么。试着逃脱社会感知或操纵的持续摆布。完全逃脱太可怕了，但可以偶尔找到掩护，找到一种扎根的感觉，相信体验是一件真实的事。

“相信体验是一件真实的事，这非常二元论。这和我的二元论哲学一致。我相信有某种神奇的东西。与其把魔法粉尘撒在程序上，我认为体验是某种真实的东西，某种分离的东西，某种神秘的东西。”

第二条：认识到善良需要天才。善良实际上非常难。轻率的善良不是善良。你需要一段时间才能拥有技能，让善良的冲动变成有效的善良。要做到有效善良很难，需要艰难的教训。你永远不会完美。但你越能做到，它就是最有回报的事。

第三条：年轻时你可能会被社交和人际情感压垮。你会心碎、嫉妒，会觉得自己在社会阶梯的下面而不是上面。那些事发生时感觉非常可怕。你必须记住，所有那些东西都只是一层脆弱的硬壳。这很难，因为事情发生时它太强烈了。

他说，如果他对自己的女儿讲这些，她早就离开房间了。这些是说给一个不太存在、真的想坐着听他声音的假想青少年听的。

一个关于未来的行动清单

拉尼尔在这场对话里给出了一条完整的替代路径。如果你想参与其中，可以从这些具体的事开始：

  • 做一次“20跳”实验：找一个匿名环境，让推荐算法带你走十七八跳，看看你会落到哪里。你会亲身体验到反馈机制粗糙带来的偏执漂移。
  • 退出或减少社交媒体，观察30天后的自己：拉尼尔收到大量邮件，人们说退出后状态好得多。他自己的邮箱是“超级糟糕的老式网站上的一个老式邮箱”，他不让社交媒体账号成为入口。
  • 支持那些有真实利益攸关的平台：GitHub 毒性低，因为人们在那里有真实的东西要被完成。选择参与那些你的贡献有实际后果、有实际代价的社区。
  • 推动数据工会的思路：如果你在贡献内容或数据，试着寻找或组织同类人的集体谈判结构。加州已经在萌芽数据工会法律。一个人一生可能属于上千个数据工会。
  • 要求三件事：对你的数据的完整控制权和透明度、随时一键带走数据的权利、以及每个人对自己的推荐算法的个体化控制权。这三个要求是对现有平台的直接挑战。
  • 对算法保持怀疑，但不必反对技术：拉尼尔说他不反数字技术，他反对的是操纵性经济。把算法当工具，不当生物。你让算法从属于你，而不是反过来。
  • 去体验一下真实世界：仰望星空，用一台真正的望远镜看一个球状星团，看看那些真实的光子。或者，摘下头显，感受感官被重新校准的那一刻。物理世界仍然是奇迹的所在。

最后一条建议来自他自己的话：要相信体验是一件真实的事，并且偶尔静下来，听一听那个被社会噪音盖住的声音。他说，真正的友谊应当把每个人介绍给对方身上意想不到的怪诞之处。也许这也可以用来对待你自己：认识你身上那个还没被算法推荐塑造过的部分。
