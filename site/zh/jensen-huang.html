Lex Fridman 问黄仁勋，一个能够从零创办、并把一家科技公司运营到十亿美元估值的 AI 系统，还需要多久。

黄仁勋说，现在已经有了。

他紧接着补了一句解释：这个标准里没有“永远”两个字。一个 agent 可以做出某个网页服务，几亿人用上两个月，每人付五毛钱，然后公司又倒闭了。互联网时代满地都是这种公司，那些网站的技术含量，大多还不如今天的 Claude 随手生成的东西。

但他在同一段话里又拆了自己的台：十万个这样的 agent 里，能长出一个 NVIDIA 的概率是零。

这两句话放在一起看才有意思。这位做了 34 年 CEO、把公司带到四万亿美元市值的人，一边把 AGI 的门槛说得极低，一边把真正的难度说得极高。中间那段距离，才是这场两个半小时对话真正在谈的东西。

问题已经装不进一台计算机了

访谈从“极端协同设计”（extreme co-design）开始。黄仁勋给了一个非常物理的解释：要算的问题已经大到一台计算机装不下。

他用的框架是阿姆达尔定律。如果你把计算部分加速一百万倍，而计算只占整个工作量的 50%，那整体只快了两倍。真正的大模型训练和推理，问题的边界早就溢出单机，你必须把算法拆开、把流水线切分、把数据和模型分片。一旦开始分布式，所有东西都变成了瓶颈。

“你加了 10000 台计算机，但你想要快一百万倍。这时候 CPU 是问题，GPU 是问题，网络是问题，交换是问题，把工作负载分配到这一堆机器上也是问题。”（黄仁勋）

摩尔定律救不了这个局面。登纳德缩放（Dennard scaling）早就慢下来了，靠制程红利拿到的性能提升，撑不起这种量级的野心。剩下的路只有一条：把每一层技术同时推到极限，各层互相让路。

六十个直接下属，没有一对一会议

Lex 问，高带宽内存、NVLink、网卡、光模块和铜缆、供电、散热，每一块都有世界级专家，你怎么把他们弄到一个房间里。

黄仁勋的回答很直接：所以我们管理层这么大。

他的直接汇报人数是 60 人，而且还在增加。这个数字在管理学教科书里是灾难，因为一对一会议根本开不完。

他的解法是取消一对一。所有问题都摆在所有人面前解。讨论散热的时候，做供电的人在听；讨论内存的时候，做网络的人在听。谁该发言而没发言，会被点名。谁觉得跟自己无关，可以走神，但代价是错过自己该贡献的那一刻。

“公司存在的目的是成为一台产出东西的机器。公司的组织架构应该反映它所处的环境。我看过很多公司的组织架构图，全都长一个样，汉堡公司的、软件公司的、汽车公司的，看起来都一样，这对我来说毫无道理。”（黄仁勋）

这段话听起来像管理鸡汤，但放到 NVIDIA 的处境里就变了味。他们每年要出货一种由 130 万个零件、200 家供应商组成的机架系统，任何单点专家做决策都会撞墙。组织形态必须长得像产品形态，否则协同设计就是一句空话。

装机量定义架构，优雅的架构全都死了

NVIDIA 起步时是一家加速器公司。黄仁勋说得很坦白，加速器的问题是应用领域太窄。市场窄带来的不只是收入少，更致命的是研发能力受限，而研发能力最终决定了你能在计算领域施加多大影响。

所以他们必须往上走，成为一家计算公司。但“加速计算”这四个字里藏着根本矛盾：计算公司做得越好，专家属性就越弱；越专注，越做不了通用计算。他把这两个词硬拼在一起，就是要逼公司走一条极窄的钢丝。

路线图是一步步铺的。先做可编程像素着色器，这是通向可编程性的第一步。然后把 IEEE 兼容的 FP32 塞进着色器，这一步使所有做流处理器的人发现了他们：原来这个算力怪兽现在能跑我写的代码了。再往上加 C，就是 Cg，Cg 最终通向 CUDA。

CUDA 能不能赢，黄仁勋的判断标准只有一个：装机量。

“没有任何架构比 x86 挨过更多的批评，它被公认不够优雅，但它今天是定义性的架构。反过来有那么多 RISC 架构，设计得极其漂亮，出自全世界最聪明的计算机科学家之手，大部分都失败了。装机量定义架构，其他一切都是次要的。”（黄仁勋）

这个判断直接推出了那个后来被反复讲述的决定：把 CUDA 装进每一块 GeForce，不管用户用不用。

市值从八十亿掉到十五亿的那笔账

这笔账很难看。CUDA 使消费级 GPU 的成本暴涨，涨幅大概 50%。当时公司毛利率 35%，这一下几乎吃掉了全部毛利。

黄仁勋在董事会上把话说清楚了：我们可能会看到这样一个世界，GeForce 背着 CUDA 的成本，但没有一个玩家因此感激，也没有一个玩家愿意为此多付钱，因为玩家只认自己的心理价位，你的成本跟他们无关。

公司市值从大约七八十亿美元跌到十五亿。他们在谷底待了一段时间，慢慢爬回来，但 CUDA 一直留在 GeForce 上。

“我总说 NVIDIA 是 GeForce 建起来的房子，因为是 GeForce 把 CUDA 带给了所有人。”（黄仁勋）

为什么 GeForce 能做到这件事。因为那个年代的 PC 是主要计算载体，还没有云。一块装在学生机箱里的显卡，等于把一台超级计算机塞进了每个实验室、每个工程院系、每个自己攒机的玩家手里。这些人后来成了深度学习革命的第一批信徒。

黄仁勋说这个决定“花了十年”才真正兑现。

他不发宣言，他每天在改别人的信念

Lex 追问的是更软的东西：你怎么敢做这种赌注。

黄仁勋的回答拆成了两层。第一层是推理。他的好奇心很重，某些时点上会有一套推理系统把某个结论推得极其清晰：这件事一定会发生。一旦他心里认定了，那个未来就会变得不容置疑。

第二层才是真正的功夫，他称之为塑造信念系统。

他明确说自己讨厌那种管理风格：领导者憋着不说，某天突然发一份宣言，新财年、新使命、新 logo、大裁员、大重组，好像公司是一夜之间换了个灵魂。

他的做法是反过来的。当他开始被某个想法影响，他会立刻告诉身边所有人：这个东西有意思，这个会影响那个。他用外部信息、新发现、新的工程突破、新的里程碑当作砖，一块一块砌进别人的认知里。这个过程每天都在发生，对董事会、对管理层、对员工。

“等到我说‘我们把 Mellanox 买下来’的那天，所有人都会觉得这是明摆着的事。很多时候看起来像是你在后面推着大家走，其实你早就在塑造他们的信念，所以在宣布的那天，是百分之百的认同。”（黄仁勋）

他举了 GTC 的例子。整个 GTC 的功能之一，就是塑造产业链上下游合作方的信念系统，然后再反过来塑造自己员工的信念。他说 OpenClaw 这套东西他讲了两块半，两年半，回头一翻就发现，原来铺垫已经铺了这么久。

这也解释了 NVIDIA 为什么不能直接卖东西给终端用户。它是平台公司，垂直整合做设计和优化，然后每一层都开放出去，被别人的产品、云、超算、OEM 机器集成。它必须先说服别人，才有生意可做。

四个扩展定律，以及“推理很简单”这个错误

黄仁勋现在是四条扩展定律的信徒：预训练、后训练、测试时、agentic。

他回顾了每一轮“到头了”的恐慌。最早是数据不够。Ilya Sutskever 说过类似“数据用完了、预训练结束了”的话，全行业慌了，以为 AI 走到尽头。

他的反驳角度挺有意思：人类互相传授的知识，本来就是合成的。

“大部分人忘了，我们用来教彼此、互相告知的绝大部分数据都是合成的。因为它不是从自然界长出来的，是你创造出来的，我消费它、修改它、增强它、重新生成，再由别人消费。现在 AI 能够拿真实数据做增强，合成出巨量的数据，后训练这一段的扩展还在继续。”（黄仁勋）

结论是：人类产生的数据占比会越来越小，训练数据的瓶颈从“有多少数据”变成了“有多少算力”。

第二阶段是测试时扩展，也就是推理。他说当年一堆人跟他讲，推理很简单，预训练才难，推理芯片会是小芯片，会商品化，谁都能自己造。

他觉得这个逻辑从一开始就不成立。

“推理就是思考，而我认为思考很难。思考比阅读难得多。预训练只是记忆和泛化，找模式、找关系，是读书；测试时扩展是推理、规划、搜索、把没见过的经验拆成可解的小块，靠第一性原理或者过往案例去解。这怎么可能是算力轻的？”（黄仁勋）

第四条是 agentic 扩展。一个 agent 在测试时跑出去查数据库、调工具，最重要的一件事是不断派生出一堆子 agent。这相当于从一个人变成一个团队。他的类比很朴素：NVIDIA 要扩张，多招人比把自己变强容易得多。

四条定律构成一个闭环。agent 跑出大量经验和数据，好的部分拿回预训练做记忆和泛化，再精调进后训练，再通过测试时和 agent 系统放回产业界，循环往复。最后剩下的唯一变量就是算力。

模型架构半年一换，硬件架构三年一换

Lex 提出了这里最要命的错配：AI 模型架构的迭代周期大概是六个月，系统和硬件架构是三年。你没法在一周内掉头。

黄仁勋承认这是最难的预测问题，然后给了三个办法。

自己做基础研究和应用研究，自己训模型。NVIDIA 是全球唯一一家跟全世界所有 AI 公司都合作的 AI 公司，能听到各家的真实困难。最后是架构本身要足够灵活，能随风转向。CUDA 的价值就在这个平衡点上：一端是极致加速，一端是极致灵活。

他举了一个具体例子。混合专家模型（MoE）出现的时候，他们的回应是把 NVLink 从 8 扩到 72。原因很实在：只有当互连域足够大，你才能把一个四万亿到十万亿参数的模型放在一个计算域里，像跑在单块 GPU 上一样。

“如果你看 Grace Blackwell 机架的架构，它完全聚焦在一件事上：跑大语言模型推理。一年之后你再看 Vera Rubin 机架，它有存储加速器，有全新的 Vera CPU，有 Vera Rubin 加 NVLink 72 跑 LLM，还多了一个叫 Rock 的机架。整个系统的设计逻辑完全变了，因为上一代是给 MoE 推理用的，这一代是给 agent 用工具用的。”（黄仁勋）

Lex 追问，这套设计早于 Claude Code、Codex、OpenClaw 出现，你怎么提前知道。

黄仁勋说，不用知道，想就行了。

人形机器人会用你的微波炉，不会从手指发射微波

他的思想实验是这样的：假设十年后我们造出了最棒的人形机器人。它进你家干活，是倾向于用你家里现成的工具，还是手在某个瞬间变成十磅重的锤子、另一个瞬间变成手术刀，为了烧水就从手指射出微波？

显然是后者荒谬。它更可能走到微波炉前，第一次不知道怎么用，但它连着网，读一遍说明书就变成专家。

这一句话就推出了 agent 系统的全部特征：它要用工具，要访问文件，要能做研究，要有一套 IO 子系统。也推出了一个更大的判断：软件不会因为 AI 而消失，说“AI 会干掉软件，我们不再需要工具”是荒谬的。

“我们用 OpenClaw 的那张架构图，你在两年前的 GTC 上就能找到。我在两年前就在讲这样的 agent 系统。当然，要发生还需要很多事汇聚到一起。首先 Claude、GPT 这些模型的能力要到那个水平，然后得有人做出一个足够健壮、足够完整的开源项目。我认为 OpenClaw 对 agent 系统的意义，就像 ChatGPT 对生成式系统的意义。”（黄仁勋）

关于 OpenClaw 为什么比 Claude Code 和 Codex 更出圈，他的答案很短：因为普通消费者够得着。

安全问题他也正面回应了。NVIDIA 派了一批安全专家过去，做了 OpenShell，已经集成进 OpenClaw。规则是“三选二”：agent 可以访问敏感信息、可以执行代码、可以对外通信，任何时刻最多给两个，不给三个。再加上基于企业权限的访问控制和策略引擎对接。

一百三十万个零件，两百家供应商，没有一份合同

Lex 把供应链的问题摆出来：ASML 的 EUV、台积电的 CoWoS 先进封装、SK 海力士的高带宽内存，这些是不是让你睡不着。

黄仁勋说，天天都在想，也天天都在做。但他不焦虑，理由很直接：我告诉他们我需要什么，他们听懂了，他们告诉我他们要做什么，我相信他们。

这套信任是怎么建立的，他讲了 DRAM 行业的故事。三年前，数据中心里给 CPU 用的 DDR 是 DRAM 行业最大的量。他挨个说服几家 CEO：HBM 现在用量极少，几乎只有超算在用，但它会成为数据中心的主流内存。听起来很荒唐，但几家 CEO 信了，投钱建 HBM 产线。

更难说服的是另一件事：把手机用的低功耗内存 LPDDR5 改造成数据中心超算用的内存。对方的反应是“手机内存给超算用？”

结果是，LPDDR5、HBM4 和 DDR 三条线，背后都是 45 年历史的老公司，去年全部创下历史记录。

机架尺度带来的连锁反应，他讲得最具体。过去超算是在数据中心里组装的，现在是在供应链里组装好，一台两到三吨整机架运过来。这意味着供应链自己要先有电。

“如果你想要 50 吉瓦的超算同时在跑，而制造这批超算需要一周，那么供应链每周就需要一吉瓦的电力来建造和测试它，在我发货之前。所以我得飞去跟合作伙伴说，以前我们是这么造 DGX 的，以后要这么造，而且我会需要你们每人投几十亿美元的资本开支。”（黄仁勋）

电网有 40% 的容量在睡觉

谈能源的时候，黄仁勋讲了一段很少被提起的东西。

电网是按最坏情况加余量设计的。最坏情况是冬天几天、夏天几天、极端天气。剩下 99% 的时间，实际负载离峰值很远，大概只跑到峰值的 60% 左右。

“99% 的时间里，我们的电网都有富余电力，它们就闲置在那里。但它们必须闲置，因为万一那时候医院要供电、基础设施要供电、机场要运转。所以我的问题是，我们能不能帮他们理解，并设计出合同机制和机架、数据中心架构，在社会基础设施需要最大电力的时候，数据中心少拿一点。”（黄仁勋）

这种时刻极其罕见。真到了那天，可以启动备用发电机，可以把负载迁到别处，可以让计算机跑慢一点，延迟变长一点，服务质量降一点，但数据不能丢。

他把这件事卡住的原因拆成三方。第一是终端客户，合同里要求六个九的可用性，签合同的人跟 CEO 不是一个人，他打赌大部分 CEO 根本不知道自己公司签了什么。第二是数据中心要能优雅降级。第三是电力公司要愿意提供分等级的供电承诺，而不是一句“扩容要五年”。

“只要你能把它说清楚，你就能把它工程化。只要它遵循物理定律和第一性原理，我觉得就没问题。”（黄仁勋）

马斯克把“这事一定要这么久吗”问到了底

Lex 请他谈谈 xAI 在孟菲斯建 Colossus 那件事，四个月，现在 20 万块 GPU 还在扩。

黄仁勋的评价集中在三点。第一是系统思维，能跨多个学科思考。第二是极简，他不停追问：这是必要的吗，非得这么做吗，非得这么久吗，一直问到所有东西都被削到不能再削，而产品必需的能力还在。第三是他会亲自到场。

“有问题他就直接去现场，说‘把问题给我看’。当你把这些组合在一起，你就能推翻大量‘我们一直都是这么干的’‘我在等他们’。每个人都有很多借口。最后一件事是，当你亲自带着这么大的紧迫感做事，会逼得所有人都紧迫起来。每个供应商都有很多客户、很多项目，他就是要自己成为所有人项目里的第一优先级，而他靠亲自示范做到这一点。”（黄仁勋）

Lex 补充了一个细节：他见过马斯克跟一线工程师一起研究怎么把线缆插进机架，就为了弄明白这个动作为什么容易出错。从每一个具体任务里积累直觉，再叠加上“我们完全换个做法”的大锤，效率就是这么被压出来的。

光速思维：74 天是怎么来的

黄仁勋说他 30 年前就在用一套方法，叫“光速”。

光速跟速度无关，它是“物理极限在哪里”的简写。内存速度、数学速度、功耗、成本、时间、人力、制造周期，每一样都要拿光速去对标。延迟和吞吐、成本和产能，各自先算出物理极限，然后再放在一起做取舍，因为追求极低延迟的系统和追求极高吞吐的系统，架构根本不同。

他最不喜欢的是持续改进。

“有人跟我说这事现在要 74 天，我们能给你做到 72 天。我更愿意把它全部推倒，问：首先解释一下为什么是 74 天，今天什么是可能的，如果我从零开始造，要多久。答案经常让你吃惊，可能是 6 天。剩下那 68 天可能是各种合理的妥协和降本，但至少你现在知道它们是什么了。而一旦你知道 6 天是可能的，从 74 谈到 6 的对话会出乎意料地有效。”（黄仁勋）

Lex 报了一组 Vera Rubin pod 的数字：7 种芯片、5 种专用机架、40 个机架、1.2 千万亿个晶体管、近两万个 NVIDIA 芯片裸片、1100 多块 Rubin GPU、60 exaflops、每秒 10 PB 的扩展带宽。黄仁勋补充：这只是一个 pod，我们大概每周要造 200 个这样的 pod。

他的复杂度原则是一句话：该复杂的地方必须复杂，但尽可能简单。所有复杂性都要被质疑一遍是否必要，剩下的都是多余的。

中国的 AI 研究者占全球一半

聊到中国，黄仁勋先摆事实：全球大约一半的 AI 研究者是中国人，而且大部分还在中国。

他给的解释里有一条很少被提到：中国不是一个单一经济体，很多省市互相竞争，市长之间在比。这就是为什么会有那么多电动车公司、那么多 AI 公司，每个品类都能冒出好几家，内部竞争激烈到疯狂，最后活下来的是极强的公司。

第二条是文化。家庭第一，朋友第二，公司第三。工程师的兄弟在对手公司，朋友在对手公司，同学遍布全行业，同学这个概念在中国是一辈子的关系。知识流动得极快，藏着技术没有意义，不如放进开源。

“他们为什么对开源的贡献那么大，很好理解，他们在保护什么呢？工程师的兄弟在那家公司，朋友在那家公司，大家都是同学。分享知识非常快，所以开源社区反过来又放大和加速了创新。极强的人才，开源带来的快速创新，加上疯狂的竞争，最后涌现出惊人的东西。这是今天世界上创新最快的国家。”（黄仁勋）

他还说了一句对比：美国的领导者大多是律师，因为他们要维持秩序和法治；而中国是从贫困里建起来的，领导者大多是工程师，是这个国家最聪明的一批头脑。他用了一个词，建设者国家。

开源 Nemotron：三个理由

NVIDIA 开源了 Nemotron 3 Super，1200 亿参数的开放权重 MoE 模型，权重、数据、训练方法全部开放。

黄仁勋给了三个理由。

第一，要做一家伟大的 AI 计算公司，必须理解模型在怎么演进。Nemotron 3 是 transformer 加 SSM 的混合结构，他们在模型架构上做基础研究，才看得清未来什么样的计算系统能跑得动。这是极端协同设计的一部分。

第二，世界级的模型作为商品可以专有，但 AI 要扩散到每个行业、每个国家、每个研究者、每个学生，全靠专有是做不到的。开源是很多行业参与 AI 革命的前提。而 NVIDIA 有规模、有动机、也有能力一直造下去。

第三，AI 不止是语言。它要用别的模态训练出来的工具和子模型，可能是生物学、化学、物理定律、流体和热力学，这些东西不全在语言结构里。他们不造车，但要让每家车厂都有好模型可用；他们不做药物发现，但要让礼来有全世界最好的生物学 AI。

台积电最难复制的是信任

黄仁勋说，关于台积电最深的误解，是以为他们只有技术。

“他们的技术当然使他们与众不同，晶体管、金属化系统、封装、3D 封装、硅光子。但真正难的是他们能编排全世界几百家公司的动态需求，客户在往上走、在退出、在加量、在减量、在拉升、在收缩，wafer start、wafer stop、紧急插单。而他们同时做到高吞吐、高良率、好成本、优秀的客户服务。他们说好的交期，wafer 就会出现。这套制造系统我只能称之为奇迹。”（黄仁勋）

第二层是文化。同时做到技术最前沿和客户服务最好，这两件事很少出现在同一家公司身上。偏技术的不擅长服务，擅长服务的技术不够前沿。

第三层是信任，他用了一个数字：三十年的合作，几百亿上千亿美元的业务，没有合同。

聊到莫里斯·张 2013 年邀请他去当台积电 CEO 的往事，他确认是真的。他说自己非常荣幸，也深知台积电是历史上最有分量的公司之一，但他心里已经看到了 NVIDIA 会成为什么，那是他一个人的责任，所以只能拒绝。

护城河：开发者的账本

Lex 请他讲 NVIDIA 最大的护城河。

黄仁勋的答案没有任何犹豫：CUDA 的装机量。他补了一句，如果今天有人做出一个 GUDA 或者 TUDA，一点用都没有，因为从来就不只是技术问题。

“CUDA 成功靠的不是三个人，是四万三千人。还有几百万开发者相信我们会继续做 CUDA 1、2、3、13，他们决定把自己的软件、把自己堆积如山的代码搬上来。”（黄仁勋）

他站在开发者角度把这笔账算了一遍：支持 CUDA，半年后它就快十倍；支持 CUDA，你能触达几亿台机器，每一朵云、每一家电脑公司、每一个行业、每一个国家；而且你百分之百相信 NVIDIA 会一直维护它、优化它的库。三件事同时成立，所以如果我今天是开发者，我会先做 CUDA，投入最多。

第二条护城河是生态。垂直整合做极度复杂的系统，水平铺开进每一家公司的计算机：谷歌云、亚马逊、Azure、CoreWeave、Nscale、礼来的超算、企业机房、基站边缘、汽车、机器人、卫星，一个架构覆盖所有行业。

从仓库到工厂，从芯片到行星

计算的单位在变。黄仁勋说，过去是 GPU，然后是计算机，然后是集群，现在是一整个 AI 工厂。

他描述自己的心理模型变了。以前发布 Ampere，他会把芯片举起来。现在举起一块芯片仍然可爱，但那不是他在造的东西。他脑子里想的是几十上百兆瓦的庞然大物，接在电网上，配着 monstrous 的散热和网络系统，上万人在里面安装，几千名网络工程师，背后还有几千人做上电调试。上电从来不是谁按一下开关，是几千人一起把它点亮。

他说希望下一次思维跃迁，是行星级。

这个转变背后有一个更大的判断：计算机从仓库变成了工厂。

“过去的计算机本质上是文件检索系统，我们预先写好、预先录好、画好，放到网上，放进文件，再用推荐系统做过滤。现在 AI 计算机是上下文感知的，它必须实时处理和生成 token。我们从一个检索式计算系统，走到了一个生成式计算系统。”（黄仁勋）

仓库不赚钱，工厂的产出直接对应公司的营收。这不只是计算方式变了，计算机在世界上扮演的角色也变了：它不再是一台计算机，它是一座工厂，用来生产能卖钱的东西。

而且这些商品开始分层了。黄仁勋说，token 正在像 iPhone 一样分层：有免费 token，有 premium token，中间还有好几档。

“智能原来是一种可扩展的商品。有极高智能的 token，用在专业场景，人们愿意付钱。有人愿意为一百万 token 付一千美元这件事，就在拐角处，不是会不会，是什么时候。”（黄仁勋）

从这座工厂往下推，他给出的判断很硬：世界 GDP 会加速增长，其中用于计算的占比会比过去高一百倍，因为计算单元不再是存储单元，而是生产单元。

至于 NVIDIA 能不能成为一家三万亿美元营收的公司，他说当然能，因为看不到任何物理极限挡在那里。他顺便讲了个老故事：当年公司第一次突破十亿美元，有位 CEO 告诉他，无晶圆厂半导体公司理论上不可能超过十亿。后来又有人说你永远超不过 250 亿。“这些都不是第一性原理的思考。”

他也承认这里有个沟通难题。NVIDIA 不做市场份额生意，他讲的那些市场几乎都还不存在。如果一家百亿美元公司说要抢 NVIDIA 的份额，股东很容易算清楚；但要让人们想象一个没有对手可抢的市场有多大，很难。

“所以这个世界的一个挑战是想象未来。但我时间很多，我会一直推理下去，一直讲下去，每一次 GTC 都会变得更真实一点。”（黄仁勋）

token 的 iPhone 时刻到了

黄仁勋说，token 的 iPhone 时刻已经来了。

指的就是 agent，尤其是 OpenClaw。他给出的证据是增长速度：这是历史上增长最快的应用，直接垂直起飞。

Lex 承认自己在机场第一次对着笔记本电脑说话写代码，还觉得有点不好意思，假装在跟人类同事讲话。黄仁勋的回答把场景推得更远：更可能的情况是 AI 一直在烦你。

“它会不停地跟你汇报，我把这个做完了，接下来要我做什么。大多数人没意识到的是，将来跟你聊天、发消息最多的那个人，是你的 claw。”（黄仁勋）

压力大就拆问题，然后忘掉

Lex 把话题转向压力。NVIDIA 现在是被各国政府拿来规划 AI 基础设施、被无数普通人拿退休金押注的公司，CEO 怎么扛。

黄仁勋先讲了他清楚知道的事实：NVIDIA 的成功对美国很重要，巨额税收、技术领导力、国家安全的所有面向、再工业化带来的就业。他也知道自己身后是一整张生态网络，还有那些因为听信电视股评买了股票、如今成了百万富翁的教师和警察。

他的处理方式跟他处理工程问题完全一样：拆。

“我问自己，现在是什么情况，什么变了，难在哪里，我打算怎么办。把问题分解成可以动手的碎片。然后只剩下一个问题：你做了没有？你自己做了，还是让别人做了？如果你推理出该做但没做，也没让别人做，那就别再抱怨了。”（黄仁勋）

他承认自己对自己挺狠。但拆解使他保持冷静，能睡着。所有可能伤到公司、伤到伙伴、伤到产业的事，他都告诉了某个人，而且是能动手的那个人。说完之后，还能做什么呢。

至于心理上的低谷，他说有的是，经常有。

其中一部分靠遗忘。他提到 AI 学习里有个重要机制叫系统性遗忘，你不能什么都记住，什么包袱都背着。

“我会很快地拆解问题、推理问题，然后把它分出去。我说‘我告诉所有人’，本质上是在分摊这个负担。另一部分是忘记。很多时候你得对自己狠一点，行了，别哭了，走吧，然后起床。再往后就是被下一个亮点、下一个未来、下一个机会吸引过去。”（黄仁勋）

他说这跟顶级运动员一样，只关心下一分，上一分已经过去了，那些难堪和挫折也是。

Lex 提到那句著名的话：如果早知道建 NVIDIA 有这么难，比预想的难一百万倍，他根本不会开始。

黄仁勋说，这恰恰是他想解释的东西：拥有孩子般的心智是一种超能力。他看任何事情，第一反应都是“这能有多难”。

“你不能事先把所有的挫折、磨难、失望都模拟一遍，你不想知道那些。你要带着‘这会很棒、会很有趣’的心态进入一段新经历，然后在里面靠耐力和韧性撑住。因为挫折一定会来，而且会以让你意外的方式到来。”（黄仁勋）

他还补了一个判断依据：只要当初推导未来的那些前提没有实质改变，那么输出的结果也不该改变，那个模拟出来的未来仍然会发生，那就继续追。

他总结了几样东西的组合：新鲜心态进入、忘掉挫折、相信自己相信的东西、同时持续重新评估。他说自己很幸运，这几样都有一点。

公开做事的人，错的时候所有人都看得见

Lex 问了一个挺尖锐的问题：成为地球上最富有、最成功的人之一，钱、权力、名声会不会使你更难承认自己错了，更难听进反对意见。

黄仁勋说，恰恰相反。因为他大量工作是在公开场合做的，错了几乎所有人都看得见。

“我在内部会议上推理的东西，很多最后会不一样。但这从来不阻止我推理。我管理的方式，就是不断在人前推理。我跟你说一件事的时候，你能看到我是怎么走到这里的，然后你自己决定要不要相信最后那个结论。”（黄仁勋）

这套方法的好处在于，别人不必反驳你的结论，他们可以反驳你的推理步骤。反驳落在半路上，大家就能一起往前走。他把这叫集体的路径搜索。

Lex 接过这个词，说了一句更狠的：容忍尴尬是一种真实的能力。多年公开地使自己出丑，当众说过一个想法、后来被证明是错的，还能承认、还能从中长出来，这在人的层面上极其困难。

黄仁勋的回应很轻。他说，他们知道我第一份工作是刷厕所。

DLSS 5：我理解他们的担心，但那不是我们在做的事

聊到游戏，Lex 提了 DLSS 5 的争议：玩家担心它把游戏画面变成 AI 味的东西。

黄仁勋先站到了对面。

“他们的视角是有道理的，我能理解他们从哪来。我自己也不喜欢 AI slop。AI 生成的内容越来越像，都很漂亮，我对这种担心是有共情的。”（黄仁勋）

然后他解释 DLSS 5 到底在做什么：它是 3D 条件化的，受 3D 引导，受真实结构数据引导。几何是美术定的，每一帧都完全忠于这个几何；它由贴图和美术的工艺作为条件，每一帧只做增强，不改动任何东西。

而且系统是开放的，你可以在未来直接提示它：我要卡通渲染，我要这种风格。它会在忠于美术风格和意图的前提下生成。

他点出了误解的来源：很多人以为游戏照原样做完发出来，然后我们在后期处理一遍。DLSS 不是这么设计的，它是跟美术一起工作的，是给美术的一件工具，美术也可以选择不用。

Lex 补了一段更宽的观察：人类对人脸极度敏感，我们正处在一个对 AI slop 敏感的时期，这其实是一面镜子，使人意识到自己真正想要的是不完美，是那些不完美的质感使世界变得动人。只要工具是用来帮人创造世界的，就很好。

黄仁勋同意，还顺手加了一句：这几年他们给开发者做了皮肤着色器，加入次表面散射，使皮肤看起来更像皮肤。游戏开发者一直在找更多表达工具，这只是又一件，用不用由他们决定。

《Doom》和《VR 战士》

Lex 问哪款游戏影响最大。黄仁勋的答案毫不犹豫：《Doom》。

理由是文化意义和产业意义的交叉点：它把 PC 从办公自动化工具变成了家庭和玩家的个人电脑。飞行模拟类游戏出现得更早，但没有《Doom》那样的普及度来完成这次转变。

如果只从游戏技术本身看，他选《VR 战士》。

Lex 提到《赛博朋克 2077》的全光线追踪，也提到自己反复重玩《上古卷轴 5：天际》，靠社区 mod 一遍遍重新体验一个已经爱上的世界。黄仁勋说他们做了 RTX Mod，使社区能把最新技术注入老游戏。

顺便还抖了个底：GeForce 到今天仍是 NVIDIA 最重要的营销策略。人在十几岁时通过《使命召唤》《堡垒之夜》认识 NVIDIA，上大学后开始用 CUDA，再后来用 Blender、达索、Autodesk。

“我们已经实现 AGI 了”

Lex 给出的 AGI 定义很具体：一个能创办、成长并运营一家十亿美元以上科技公司的 AI 系统。

黄仁勋说，现在已经实现了。

他的理由是抠字眼：你说十亿，你没说永远。一个 Claude 做出某个网页服务，几亿人用了两个月，每人付五毛，然后公司倒闭，这算不算。互联网时代满地都是这种公司，那些网站的技术复杂度，还不如今天 OpenClaw 能生成的东西。

但他紧接着把话说回来：十万个这样的 agent 里，跑出一个 NVIDIA 的概率是零。

然后他把话题拐到了他最想说的部分，工作焦虑。

“你的工作的目的，和你用来完成工作的任务和工具，是相关的，但不是一回事。我这份工作做了 33 年，是全世界在任最久的科技公司 CEO，34 年。这 34 年里我用的工具一直在变，有时候在两三年里剧变。但目的没变。”（黄仁勋）

他讲了那个被他反复讲的案例：放射科医生。

当年 AI 研究者预言，计算机视觉会达到超人水平，所以放射科医生这个职业会消失。2019 到 2020 年，计算机视觉真的达到了超人水平。今天每一个放射学平台和软件包都是 AI 驱动的。

但放射科医生的数量增长了，而且全世界现在缺放射科医生。

“那个危言耸听的警告走得太远了，它吓退了一批本可以进入这个对社会极其重要的职业的人。所以它造成了伤害。为什么错？因为放射科医生的目的是诊断疾病、帮助病人和医生诊断疾病。当你能更快地读片，你就可以读更多片、诊断得更好、病人更快入院、能见更多人，医院赚更多钱，住院病人更多，你就需要更多放射科医生。”（黄仁勋）

同样的逻辑放在 NVIDIA：软件工程师的人数会增长，不会减少。因为目的是解决问题，不是写多少行代码。

编程的定义变了，从三千万人变成十亿人

Lex 顺着问：那全世界的程序员数量会不会增加。

黄仁勋说会，理由是他重新定义了编程。今天的编程就是写规格说明，如果你想更强势一点，你甚至可以指定软件架构。问题是，有多少人能做这件事。

“我觉得我们刚从三千万人涨到了十亿人。未来每一个木匠都是一个程序员，只不过一个有 AI 的木匠同时还是建筑师。他们能交付给客户的价值被提升了，他们的工艺水平被大幅抬高了。每一个会计同时也成了你的财务分析师、你的财务顾问。如果我是木匠，看到 AI 我会彻底疯掉，我能给客户提供的服务太强了。如果我是水管工，也一样。”（黄仁勋）

他自己在工作中也是这样。给公司定战略、定方向的时候，他会把话说得足够具体，使人能行动，但故意欠规格，留出让 43000 个优秀的人把它做得比他想象的更好。

所以规格的工艺水平取决于你在解决什么问题、你在跟谁合作。你可以非常规定性，因为你要一个确定的结果；也可以故意欠规格，使 AI 反过来推你自己的创造力边界。这个谱系上的位置感，就是编程的未来。

他给大学生的建议很短：如果你今天招一个应届生，一个完全不懂 AI，一个是 AI 专家，我要 AI 专家。会计、市场、供应链、客服、销售、商务、律师，都一样。每个大学生毕业时都该是 AI 专家。如果你是木匠、电工、农民、药剂师，去用 AI，看看它能怎么改造你现在的活，把你自己变成这个行业的革新者。

Lex 补了一个更日常的角度：AI 最好用的地方之一是它能帮你拆解焦虑。“我担心我的工作”，然后它会给你一份逐条的行动计划。而且它把初学者的门槛拆掉了。你没法走到 Excel 面前说“我不会用 Excel”，那你就完了；但你可以跟 AI 说“我不会用 AI”，它会说“来，我教你”。

智能是商品，人性不是

Lex 问，有没有什么东西是人类意识里根本不可计算的，再强的芯片也复制不了。

黄仁勋的回答分两半。他不确定芯片会不会紧张。他相信 AI 能识别、理解紧张和焦虑，但芯片本身不会感到这些。而恰恰是这些感受在人类表现里显现出来：同样的处境，不同的人做出完全不同的成绩，那个谱系来自情绪，不来自计算。

“我不觉得我们造的任何东西会表明，两台计算机在完全相同的情境下会有根本不同的表现。当然统计上会有差异，但那不是因为它们感受不同。”（黄仁勋）

然后他把话锋转向了“智能”这个词本身。

“重要的是拆解什么是智能。这个词我们天天用，但它不神秘。智能是一个系统，包含感知、理解、推理、规划的能力，这个循环就是智能的根本。智能不等于人性，这是两个词。我不把智能过度浪漫化。我其实认为智能是一种商品。”（黄仁勋）

他拿自己举例。他身边全是比他聪明的人，学历比他好，学校比他好，在各自领域里钻得比他深。他的 60 个直接下属，对他来说都是超人。而他就坐在中间调度这些人。

“所以你不得不问自己，一个洗碗工凭什么坐在一群超人中间？这说明什么？我的意思是，智能是功能性的东西，人性不是用功能定义的，它是一个大得多的词。我们的生活经验、我们对痛苦的耐受、我们的决心，那些是跟智能完全不同的词。”（黄仁勋）

他说如果只能给听众留一样东西，那就是这个：我们社会把所有东西都压进了“智能”这一个词，而生活不止一个词。他自嘲说，他这一生恰好证明，在智能曲线上低于身边所有人，并不妨碍他成为最成功的那个。

所以别让智能的民主化、商品化带来焦虑，这件事值得为此感到鼓舞。

我不相信继任计划

Lex 问得很直接：你想过自己的死亡吗，你怕吗。

黄仁勋说，他真的很不想死。他有很好的生活、很好的家庭、很重要的工作。

“这不是一生一次的体验，这是人类史上一次性的体验，我正在经历的这个东西。NVIDIA 是历史上最有分量的科技公司之一，我们在做非常重要的事，我非常认真地对待它。”（黄仁勋）

然后他提到了继任计划，并且明确说自己不信这套。

他不信的理由不是觉得自己不会死。他的推理是：如果你为继任计划焦虑，那就把这个焦虑拆到底，今天最该做的事是什么。答案是：如果你关心你离开之后的公司，那就尽可能频繁、尽可能持续地把知识、信息、洞察、技能、经验传下去。

“这就是为什么我一直在团队面前推理。每一场会议都是推理会议。我在公司内外的每一刻，都是在尽可能快地把知识传给人们。我学到的任何东西，在我桌上停留的时间不超过零点几秒。我还没完全学明白，就已经在指给别人看了：快上，这个太酷了，你会想学的。”（黄仁勋）

所以他希望的结果是死在岗位上，最好是瞬间的那种，没有漫长的痛苦。

把智能请下神坛

最后 Lex 问，什么使你对人类和未来抱有希望。

黄仁勋说他一直对人的善良、慷慨、同情心和能力有极大的信心，有时候信心大过头，会被人占便宜，但这不会改变他的起点：人想做好事，人想帮别人。而绝大多数时候他都被证明是对的，而且常常超出预期。

使他真正兴奋的是现在能看到什么是可能的。

“有那么多问题我们想解决，有那么多东西我们想造，有那么多好事现在落在了我们够得着的地方，落在我这一辈子的范围内。你不可能对此不感到浪漫。”（黄仁勋）

他列举得很具体：疾病终结是一个合理的预期，污染大幅下降是一个合理的预期，以光速旅行在短距离内进入我们的未来，也是一个合理的预期。他还开了个玩笑：很快我会把一个机器人送上飞船，使它一路飞行一路自我改进，等到时候，我这辈子说过的话、写过的邮件早就上传成了我的 AI，用光速发过去追上那个机器人就行。

Lex 提到生物机器的破解就在眼前，黄仁勋说不是十年，大概是五年。意识如何解释，那个答案会很棒。

整场对话走到这里，其实有一条很清楚的线。他把智能拆成功能性能力，然后说它是商品；他把人性、品格、同情、耐力、决心拎出来，说那些才是超能力。他对 AGI 的定义给得极松，对做成一家 NVIDIA 的难度说得极紧。他一边用第一性原理把 74 天压到 6 天，一边承认如果早知道有多难，他根本不会开始。

这些说法看起来互相打架，其实指向同一件事：真正稀缺的从来不是算力，也不是智能，是在看不到尽头的时候还愿意每天往前挪一点的那种人。

给读完这篇的人，几条可以直接动手的事：

  • 今天就找一个你工作里最耗时的任务，把它的完整流程讲给 AI 听，请它给出一份操作方案。不要问“AI 能做什么”，要问“我这个具体的事怎么做”。
  • 练一件事：把问题拆到能动手为止。写下你现在最焦虑的那件事，拆成“我能做的”和“我做不了的”两栏，然后把第一栏的每一项都指给一个能动手的人，包括你自己。
  • 如果你在带团队，别发宣言。把你在想的事情提前几个月、按周铺进日常对话里，等真正宣布的时候，使大家的反应是“你怎么才说”。
  • 给自己设一个“光速”参照。下次有人告诉你某件事要 74 天，先别谈折扣，问一句：如果从零开始造，物理上最快是多少天。
  • 学一点编程，哪怕你不打算当程序员。写规格说明就是新的编程，你描述得越清楚，AI 交付的东西越接近你脑子里那个版本。
  • 如果你是学生、老师、木匠、会计、医生，任何职业，把“熟练使用 AI”当成和识字一样的基础能力，别等它变成门槛才开始。
